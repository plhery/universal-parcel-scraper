# FUTA Express

FUTA Express shipments use enabled universal providers. There is no dedicated adapter.

FUTA Express carries parcels on the Phương Trang (FUTA Bus Lines) coach network between Vietnam's provinces. It is on Vietnam's list of licensed postal enterprises.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The home page's tracking box reads `GET /f1/full-bill-by-code-public/<number>` from FUTA Express's back-office
API without a login. With no public number to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
