# Fixtures

Replies of CityMail's `POST my.citymail.com.pk/get-tracking-data-web`.

- `cancelled.json`: the reply for the public sample in [`numbers.json`](../numbers.json), as it came: a
  consignment booked in Dubai for Dubai and cancelled the next night. Its head names the shop that booked it
  and the shop's reference; it names no recipient.
- `not-found.json`: the answer for a number CityMail does not know.
