# DPE Express

DPE Express parcels use enabled universal providers. There is no dedicated adapter.

DPE Express (递必易, Delivery Perfect Express) is a Guangzhou forwarder running lines from China to
Malaysia, Singapore and the Philippines, with its own warehouse and delivery in Malaysia. Its site
is dpe.net.my. It is not [DPEX](../dpex/README.md).

## Numbers

Its waybills are eleven digits, a length many carriers' rules accept, so there is no rule.

## Why there is no adapter

Its tracker shows results only after an image CAPTCHA.

## Links

Its tracker takes numbers in a form, so no portal link is published.
