# transportami

transportami shipments use enabled universal providers. There is no dedicated adapter.

transportami, from Eschweiler, sells pallet and general-cargo shipments online to businesses and private senders and
hands them to partner hauliers.

## Numbers

Its order numbers are eight digits. No public page shows one, so there is no rule.

## Why there is no adapter

Each lookup needs the order number and the order date; the recipient's postcode adds the addresses. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
