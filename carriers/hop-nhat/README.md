# Hợp Nhất Express

Hợp Nhất Express shipments use enabled universal providers. There is no dedicated adapter.

Hợp Nhất Express (HNC) is a domestic and international express courier from Hanoi. It is on Vietnam's list of licensed postal enterprises.

## Numbers

Its waybills have 15 digits, as the tracking form's example shows. New Post's older waybills have the same
shape, so there is no rule.

## Why there is no adapter

With no public number to check the tracker's replies against, there is no adapter.

## Links

The form sends `hawbNos` with a token from the page it was loaded on, so no address opens one shipment.
