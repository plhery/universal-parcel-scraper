# Eurosender

Eurosender shipments use enabled universal providers. There is no dedicated adapter.

Eurosender, from Luxembourg, books parcel, pallet and freight shipments across Europe with partner carriers, on
sites in French, English, German, Spanish and Italian.

## Numbers

Its order numbers are six digits, a hyphen and two digits; the tracker also takes the partner carrier's number.
No public page shows an order number, so there is no rule.

## Why there is no adapter

The tracker asks Eurosender's API with the number and an optional postcode, then opens the detailed page its
answer names. With no public number to check the tracker's replies against, there is no adapter.

## Links

The page reads the number only from its form, so no address opens one shipment.
