# SYD Express

SYD Express parcels use enabled universal providers. There is no dedicated adapter.

SYD Express (速邮达物流) is a Shenzhen forwarder selling postal small-parcel lines and express
services. Its site is suyd56.com; 速邮达 on suyoda.cn is a different company, so the bare name is not
an alias.

## Numbers

Most of its products carry a partner's number, and no public page shows an SYD number, so there is
no rule.

## Why there is no adapter

Its tracker is a tenant of the Kingtrans platform, which answers an open XML lookup without a
session or CAPTCHA. No public number is known to see a found reply.

## Links

The Kingtrans tracking page opens the number from its `bills` parameter.
