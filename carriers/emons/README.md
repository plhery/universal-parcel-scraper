# Emons

Emons parcels use enabled universal providers. There is no dedicated adapter.

Emons is a Cologne groupage forwarder delivering pallets and parcels across Germany. Its site is emons.de.

## Numbers

Its shipment numbers are 20-digit GS1 shipping codes, which other carriers print too, so there is no rule.

## Why there is no adapter

Its tracker reads an open JSON lookup but needs the recipient's postcode with the number.

## Links

The tracker's links carry the recipient's postcode, so no link names it.
