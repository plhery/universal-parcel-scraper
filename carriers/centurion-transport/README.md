# Centurion

Centurion parcels use enabled universal providers. There is no dedicated adapter.

Centurion (Centurion Transport Co.) is a Western Australian road freight, heavy haulage and
warehousing company with depots across Australia. Its site is centurion.net.au.

## Numbers

The only public consignment note is two letters and eight digits, from an archived lookup on its
older proof-of-delivery search. That layout is common and rests on one number, so there is no
rule.

## Why there is no adapter

Its site refuses many networks outside Australia, and no current public consignment note has
been found.

## Links

The consignment search opens a note from its `con` parameter.
