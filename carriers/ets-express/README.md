# ETS Express

ETS Express (俄通收) parcels use enabled universal providers. The carrier's
[inquiry page](https://www.ets-express.com/inquiry.html) submits the shipment
reference over plain HTTP, so automated recognition and tracking skip that endpoint.

Use the carrier's RETS shipment number. Ozon posting references stay with
[Ozon](../ozon-logistics/README.md). See the [provider testing instructions](../../providers/README.md)
for provider-specific tests.
