# New Post

New Post shipments use enabled universal providers. There is no dedicated adapter.

New Post is a domestic express courier from Ho Chi Minh City. It is on Vietnam's list of licensed postal enterprises.

## Numbers

[New Post's notice](https://newpost.vn/blogs/tin-tuc/thong-bao-ve-viec-thay-doi-ma-so-dau-bill) moved its
waybills from 15 digits to 9. Both shapes are common to other carriers, so there is no rule.

## Why there is no adapter

With no public number to check the tracker's replies against, there is no adapter.

## Links

`newpost.vn/tracking?code=<number>` is the tracking form's own address for one waybill.
