# Athinaiki

Athinaiki parcels use enabled universal providers. There is no dedicated adapter.

Athinaiki (Γενικές Μεταφορές Αθηναϊκή Α.Ε.) is a general carrier in Aspropyrgos, Attica, Greece,
with its own stores in the largest Greek cities, agents across the country and last-mile delivery
for online shops. Its site is athinaiki.gr.

## Numbers

No public page shows an Athinaiki number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page posts a number with a page token from a script and shows the answer in the page.
With no public number to check its replies against, there is no adapter.

## Links

The form posts the number with a token, so no address opens one item.
