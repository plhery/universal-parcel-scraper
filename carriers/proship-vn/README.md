# Proship

Proship shipments use enabled universal providers. There is no dedicated adapter.

Proship carries parcels and freight by road and rail across Vietnam, in the RATRACO railway group. It is on Vietnam's list of licensed postal enterprises.
It is not the Colombian [ProShips](../proships/README.md).

## Numbers

No public page shows one of its order codes, so there is no rule.

## Why there is no adapter

The order finder posts the code with a reCAPTCHA answer to the site's `admin-ajax.php`. With no public
number to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
