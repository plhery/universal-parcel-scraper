# BM Express

BM Express shipments use enabled universal providers. There is no dedicated adapter.

BM Express International Services ships balikbayan boxes to the Philippines from Minto, New South Wales, and from
New Zealand, Singapore, the United Kingdom and Papua New Guinea.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The trackers are Wix pages, one per origin, that answer a reference number through the site's own web methods.
With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
