# W Express

W Express parcels use enabled universal providers. There is no dedicated adapter.

W Express (Wide Wide World Express Corporation, formerly WWWExpress) is a Philippine express
courier with branches across the country, carrying documents and parcels door to door. It was
once DHL's Philippine company, but that name is not an alias, since it belongs to DHL. Its site is
wwwexpress.com.ph.

## Numbers

Its waybills have ten digits, a length many carriers share, and no public page shows one, so there
is no rule.

## Why there is no adapter

The tracking page loads an open server-rendered page without a session or CAPTCHA. No public
number is known to see a found reply.

## Links

The tracking page and the page it loads open the number from their `trackingNo` parameter.
