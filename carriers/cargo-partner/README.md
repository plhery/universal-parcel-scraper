# cargo-partner

cargo-partner shipments use enabled universal providers. There is no dedicated adapter.

cargo-partner, from Fischamend near Vienna and part of Nippon Express, forwards air, sea and road freight worldwide.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The public tracker asks a reCAPTCHA before a search. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker's script reads a search from its address, but no public page shows how a shipment opens, so there is no
link rule.
