# LBC Express

Catalog and tracking-link support for LBC Express, with the Philippines as its home market. Automatic lookup uses the universal providers the consumer enables.

There is no dedicated adapter. The public website's tracking flow is unavailable to this integration; no anonymous developer tracking feed is integrated. Numeric tracking IDs overlap other carriers and remain detection candidates.

Provider testing and configuration are described in [the provider comparison](../../providers/COMPARISON.md). Run the applicable provider live test with an LBC input supplied outside Git.
