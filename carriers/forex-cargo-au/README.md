# Forex Cargo Australia

Forex Cargo Australia shipments use enabled universal providers. There is no dedicated adapter.

Forex Cargo Australia ships balikbayan boxes from Ingleburn, New South Wales, to the Philippines. It shares a
brand with the American [Forex Cargo](../forex-cargo/README.md) but runs its own site and tracker.

## Numbers

No public page shows one of its reference numbers, so there is no rule.

## Why there is no adapter

The tracker is an Inertia.js page that answers a reference number with the box's details. With no public number
to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
