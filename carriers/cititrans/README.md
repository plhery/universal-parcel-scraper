# Cititrans

Cititrans parcels use enabled universal providers. There is no dedicated adapter.

Cititrans (亦邦物流) is a Shenzhen forwarder for the Middle East and Africa, with its own last mile in
the United Arab Emirates and Saudi Arabia. Its site is cititrans.com.

## Numbers

The tracking page's built-in example is a freight order, and no public page shows a parcel number,
so there is no rule.

## Why there is no adapter

The tracking page asks two open JSON endpoints, one for freight orders and one for parcels, without
a session or CAPTCHA. No public number is known to see a found reply.

## Links

The tracking page takes the number in its form, so no address opens one parcel.
