# time:matters

time:matters parcels use enabled universal providers. There is no dedicated adapter.

time:matters is a same-day and on-board courier in Neu-Isenburg near Frankfurt. It moves
time-critical shipments by air, rail and road, with on-board couriers, charters and its own
courier terminals, and has offices in Austria, the Netherlands, the United States, China,
Singapore and Malaysia. Its site is time-matters.com.

## Numbers

Its tracking form takes S and digits, or eight or nine digits, each with an optional dash and
digits after it. Those shapes are too generic for a rule, and no public page shows one.

## Why there is no adapter

Its tracking page is a JavaScript app that reads
`booking.time-matters.com/services/css-orders/orders/<number>/status/basic`. No public number is
known to see a found reply.

## Links

`booking.time-matters.com/en-US/tracking/<number>` opens one shipment, and so does the same page
in another language.
