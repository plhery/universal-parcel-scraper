# Span Alaska

Span Alaska shipments use enabled universal providers. There is no dedicated adapter.

Span Alaska, from Auburn, Washington, and part of Matson, consolidates less-than-truckload freight from the lower 48
states to Alaska.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The portal's tracker reads the PRO number from its address. With no public number to check the tracker's replies against, there is no adapter.

## Links

`portal.spanalaska.com/tracker?pro=<number>` opens one shipment; the portal also reads `pronum` and `shipmentid`.
