# DAGO Express

DAGO Express parcels use enabled universal providers. There is no dedicated adapter.

DAGO Express is a courier and direct-transport company in Frankfurt (Oder). It runs same-day and
overnight express and direct van and truck runs across Germany and to other European countries,
partly with partner drivers. Its site is dagoexpress.com.

## Numbers

No public page shows a DAGO Express number and their format is unknown, so there is no rule.

## Why there is no adapter

Its tracking page at app.dagoexpress.com is a JavaScript app that asks for the tracking number and
the receiver's postcode, and shows nothing for the number alone.

## Links

The tracking page opens an order only when the address also carries the receiver's postcode, so
no address opens one parcel from its number.
