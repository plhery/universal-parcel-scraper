# M+R Spedag

M+R Spedag shipments use enabled universal providers. There is no dedicated adapter.

M+R Spedag Group, from Muttenz near Basel, forwards sea, air and road freight.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracking page posts the MRS tracking code, with the customer's reference, back to the site. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
