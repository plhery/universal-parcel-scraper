# TTK Europe

TTK Europe parcels use enabled universal providers. There is no dedicated adapter.

TTK Europe is a Manchester parcel line shipping from the UK to China, where China Post delivers. Its site is
ttkeu.com.

## Numbers

Its tracker gives `TE`, nine digits and `GB` as its layout, the UPU S10 form that Royal Mail's rule takes when
the check digit passes. No public page shows a TTK Europe number, so there is no rule.

## Why there is no adapter

Its tracker reads an open JSON API without a session or CAPTCHA, which says when a number does not exist. No
public number is known to see a found reply.

## Links

The tracking detail page opens numbers from its `id` parameter.
