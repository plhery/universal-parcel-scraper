# Guisnel

Guisnel shipments use enabled universal providers. There is no dedicated adapter.

Groupe Guisnel, from Dol-de-Bretagne, delivers and assembles furniture and kitchens at home for retailers, with two
people per delivery. Transporter mon meuble is its service for private people.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

"Suivre ma commande" on guisnel.com opens a ProfoundUI application hosted by its transport software's supplier,
TRAPLUS. With no public number to check the tracker's replies against, there is no adapter.

## Links

The application reads the order only from its own screen, so no address opens one delivery.
