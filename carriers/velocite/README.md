# Vélocité

Vélocité shipments use enabled universal providers. There is no dedicated adapter.

Vélocité delivers by bike and cargo bike in Lausanne, on the Riviera (Vélocité Riviera, Vevey), in Yverdon and in
Valais; national legs travel with swissconnect.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The home page's tracking box asks `dispo.velocite.ch/api/apitrack.php` for the code's status, date and signature.
With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
