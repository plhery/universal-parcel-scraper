# DG Transporte

DG Transporte parcels use enabled universal providers. There is no dedicated adapter.

DG Transporte is a courier from Kirchheim unter Teck carrying express shipments and valuables in Germany. Its
site is dg-transporte.de.

## Numbers

No public page shows a DG Transporte number, so there is no rule. Parcels it books with DPD keep DPD's numbers.

## Why there is no adapter

Its tracker posts the number with the recipient's postcode.

## Links

Its tracker has no address for a single number, so no link names it.
