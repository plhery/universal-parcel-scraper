# Burundi Post

Burundi Post parcels use enabled universal providers. There is no dedicated adapter.

Burundi Post, the Régie Nationale des Postes, is Burundi's postal operator. Its site is poste-burundi.bi.

## Numbers

Its items carry UPU S10 numbers ending `BI`, which postal detection reads. No public page shows one,
so there is no rule of its own.

## Why there is no adapter

Its tracker posts the number in a form without a session or CAPTCHA and answers an unknown number with only a
heading. No public number is known to see a found reply.

## Links

Its tracker has no address for a single number, so no link names it.
