# Streck Transport

Streck Transport shipments use enabled universal providers. There is no dedicated adapter.

Streck Transport, from Lörrach, carries general cargo and handles customs between Germany and Switzerland.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

myStreck is a customer portal; its "Direkt zur myStreck Sendungsverfolgung" button opens a barcode search with a guest
token every visitor gets. With no public number to check the tracker's replies against, there is no adapter.

## Links

The search reads the barcode only from its own screen, so no address opens one shipment.
