# Spike

Spike items use enabled universal providers. There is no dedicated adapter.

Spike is the private postal network of Post & Service of Modugno, which delivers registered and ordinary
mail, including the items of [Mail Express](../mail-express-it/README.md). Post & Service
is on the Italian Ministry of Enterprises' register of postal operators.

## Numbers

Items carry a barcode whose layout no public page shows, so there is no rule.

## Why there is no adapter

The tracking page posts the number as `barcode` from its form and answers with a server page. With
no public number to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one item.
