# Fixtures

`delivered.json` is the tenant's `queryTracks` reply for the public sample in
[`numbers.json`](../numbers.json), from TrackShip's U-Speed Express page
(<https://trackship.com/shipping-provider/u-speed-express/>). In its two text messages the
recipient's name, the street address, the driver's name and the driver's phone are replaced
with `[removed]`; the rest is as received. `not-found.json` is the answer for an invented
number of the same shape.
