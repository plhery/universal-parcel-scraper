# Southwest Airlines Cargo

Southwest Airlines Cargo shipments use enabled universal providers. There is no dedicated adapter.

Southwest Airlines Cargo carries airport-to-airport and same-day freight on Southwest's flights across the US.

## Numbers

Its air waybills are the prefix 526 and eight digits, a shape every airline shares, so there is no rule.

## Why there is no adapter

The tracker opens a results page for the air waybill. With no public number to check the tracker's replies against, there is no adapter.

## Links

The results page reads `trackingInfo`, the air waybill written with its prefix and a hyphen; the catalog's link
template cannot rewrite a number that way, so there is none.
