# Runner Express

Runner Express parcels use enabled universal providers. There is no dedicated adapter.

Runner Express is an Israeli importer of cross-border e-commerce parcels: customs, warehousing
and delivery through last-mile partners. Its site is runnerexpress.co.il.

## Numbers

No public page shows a Runner Express tracking number, so no rule names it.

## Why there is no adapter

The tracker answers a plain GET, but no public number has been found to check it with.

## Links

The tracker opens a number from its `search_query` parameter.
