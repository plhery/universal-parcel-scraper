Replies of YJI's Hualei tracker. `track.json` is the interface's record for the public sample in
[`numbers.json`](../numbers.json), decoded from GBK, with the shipper's account code replaced:
the forwarder's own rows and voyage notes, the platform's script for the voyage, and the rows
copied from FedEx. `no-track.json` and `page-unknown.html` are the live answers for an unknown
number.
