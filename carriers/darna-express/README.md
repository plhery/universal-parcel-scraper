# Darna Express

Darna Express shipments use enabled universal providers. There is no dedicated adapter.

Darna Express ships balikbayan boxes from British Columbia, Canada, to the Philippines.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracking page reads the box from the site's Firebase database, not from an HTTP API. With no public number to
check its answers against, there is no adapter.

## Links

`darnaexpress.com/track/<number>` opens one box.
