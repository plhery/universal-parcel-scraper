# Canada Air Express

Canada Air Express parcels use enabled universal providers. There is no dedicated adapter.

Canada Air Express (加拿大民航快递, Canada GTL Express) is run by Golden Territory Logistic of
Richmond, British Columbia. It carries parcels from Canada to China through agent stores in British
Columbia, Alberta, Saskatchewan and Toronto. Its site is air-gtc.com.

## Numbers

Its site gives no number layout and no public page shows a Canada Air Express number, so there is
no rule.

## Why there is no adapter

Its waybill page answers `GET main.air-gtc.cn/WaybillInfo.aspx?KeyWord=` with HTML, without a
session or CAPTCHA. An unknown number gets an alert that it does not exist. No public number is
known to see a found reply.

## Links

The waybill page opens the number from its `KeyWord` parameter.
