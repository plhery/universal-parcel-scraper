# Manila Forwarder

Manila Forwarder shipments use enabled universal providers. There is no dedicated adapter.

Manila Forwarder ships balikbayan boxes and air cargo to the Philippines from Los Angeles, other American
cities, Denmark and Papua New Guinea.

## Numbers

The tracking page lists each origin's number layout, a short prefix such as MF or SET and four to seven
digits. The layouts are too short to tell its numbers from other carriers', so there is no rule.

## Why there is no adapter

The tracker posts the number in a form. With no public number to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
