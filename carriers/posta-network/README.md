# Posta Network

Posta Network items use enabled universal providers. There is no dedicated adapter.

Posta Network, in the province of Teramo, which calls itself OK Poste Private, is a private post for registered and
ordinary mail with "data certa" tracking, printing and enveloping. It is on the Italian Ministry of
Enterprises' register of postal operators.

## Numbers

No public page shows a number or its layout, so there is no rule.

## Why there is no adapter

The home page's form posts the number as `trackk` to
`app.postanetwork.it/area-riservata/ajax.php?ricerca_track=PostaNetwork`, which answers with the
latest outcome and its date, or `error`. It has no history, and with no public number to check its
replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one item.
