# LBTX

LBTX parcels use enabled universal providers. There is no dedicated adapter.

LBTX (Longben Tianxia) is a Shenzhen forwarder running parcel lines from China to Europe and North America.
Its site is lbtxkd.com.

## Numbers

No public page shows an LBTX number, so there is no rule.

## Why there is no adapter

Its tracker posts numbers to an HTML page without a session or CAPTCHA, which marks an unknown number as not
found. No public number is known to see a found reply.

## Links

Its tracker has no address for a single number, so no link names it.
