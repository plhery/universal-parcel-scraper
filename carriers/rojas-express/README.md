# Rojas Express

Rojas Express parcels use enabled universal providers. There is no dedicated adapter.

Rojas Express is a Madrid courier for urgent parcels across Spain, for businesses and private
customers.

## Numbers

No public page shows a Rojas Express number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `rojasexpress.factapp.es`. No
public number is known to check its replies against.

## Links

The company's own tracking page is a contact form, so the catalog uses its IRIS tracker.
`/IRIS/Seguimiento?s=<number>` opens one shipment, so the catalog links each number there. Each IRIS
tenant keeps its own shipments, so links are read only on the company's tenant.
