# Faster Express & Cargo

Faster Express & Cargo parcels use enabled universal providers. There is no dedicated adapter.

Faster Express is a Dubai forwarder moving Chinese shippers' goods to the Gulf states, with customs
clearance, warehousing and delivery. Its site is faster.ae.

## Numbers

No public page shows a Faster Express number, and the example on its tracker returns demo data, so there is
no rule.

## Why there is no adapter

Its tracking page and operations portal read open JSON APIs without a session or CAPTCHA, which answer an
unknown number with a not-found. No public number is known to see a found reply.

## Links

The tracking page opens numbers from its `no` parameter and the operations portal from its `ids` parameter.
