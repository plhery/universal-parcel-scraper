# Everts Air Cargo

Everts Air Cargo shipments use enabled universal providers. There is no dedicated adapter.

Everts Air Cargo, from Fairbanks, flies freight and fuel to communities across Alaska.

## Numbers

Its air waybills are the airline's three-digit prefix and eight digits, a shape every airline shares, so there is no rule.

## Why there is no adapter

The tracker is an Everts page on its cargo software supplier's site. With no public number to check the tracker's replies against, there is no adapter.

## Links

`apps1.tflite.com/Public/EVT/Freight/Tracking/<number>` opens one shipment; EVT is Everts' account there, so the
link rule matches only that path.
