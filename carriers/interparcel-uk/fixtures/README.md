# Fixtures

Tracking pages the browser rendered after Cloudflare's check, for the public samples in
`numbers.json`. Each keeps the page's tracking pane, from the delivery banner to the detailed
list; the site's menus, styles, scripts, map and booking forms are left out. The signer's
name is replaced with `A. Sample`.

Each sample's page is named after it: a FedEx parcel from Leeds to France, signed for, and an
older Parcelforce parcel to Guernsey whose summary leaves out the booking. `not-found.html` is
the empty track form the site answers for a reference it does not hold.
