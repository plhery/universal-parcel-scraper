# DeliverDirect

DeliverDirect parcels use enabled universal providers. There is no dedicated adapter.

DeliverDirect is Delta Cargo's e-commerce delivery service in the United States, built with SmartKargo on
the platform Kart2Door uses. Its site is deliverdirect.com.

## Numbers

No public page shows a DeliverDirect number, so there is no rule.

## Why there is no adapter

Its tracker renders results as HTML without a session or CAPTCHA and answers an unknown number with a
not-found message. No public number is known to see a found reply.

## Links

The tracker opens numbers from its `axb` parameter.
