# Aetos Courier

Aetos Courier parcels use enabled universal providers. There is no dedicated adapter.

Aetos Courier is a courier in Piraeus, Greece, that delivers in Attica. Outside Attica it hands
parcels to ACS, and abroad to DHL, which track them under their own numbers. Its site is
aetoscourier.gr.

## Numbers

No public page shows an Aetos Courier number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page runs on Pegasus Hermes, the courier software behind
[Pack-Man](../pack-man/README.md)'s former voucher search, and shows vouchers, several separated by
commas, with their status, order number and sender. With no public number to check its replies
against, there is no adapter.

## Links

The voucher search opens numbers from its `r18p01` parameter.
