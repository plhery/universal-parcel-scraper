# Fixtures

The replies follow `getTrackingByNos` for one number as the tracker sends it: a JSON string
holding a JSON array with one item, its summary status in Chinese, the countries in Chinese and
the scans in English, newest first. The rows in the United States open with the town, state and
ZIP code.
`in-transit.json` goes from the order data through import clearance to the last-mile network's
sorting centre.
`not-found.json` has the shape of the system's answer for a number it does not know.

Numbers, places and clocks are invented.
