# Spourgitis Trans

Spourgitis Trans parcels use enabled universal providers. There is no dedicated adapter.

Spourgitis Trans (Σπουργίτης) carries parcels and removals door to door from Greece to Europe, the
UK, Cyprus, North America and Australia, under its own waybills. Its site is spourgitis.gr.

## Numbers

No public page shows a Spourgitis Trans number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows a waybill's status and history. With no public number to check its replies
against, there is no adapter.

## Links

Its form opens the tracking page with a `shipping_code` parameter beside a value the page issues
each time, so no fixed address opens one item. Links read `shipping_code` from the Greek or English
page.
