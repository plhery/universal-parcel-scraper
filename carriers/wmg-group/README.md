# WMG

WMG parcels use enabled universal providers. There is no dedicated adapter.

WMG (WMG Pte Ltd) is a Singapore licensed postal operator that delivers cross-border e-commerce
parcels and runs last-mile delivery in Singapore. Its tracker is a box on its home page.

## Numbers

No public page shows a WMG number, so there is no rule. Its tracker also shows the number of
the partner carrier that delivers abroad.

## Why there is no adapter

The tracking box sends each lookup with a CAPTCHA token, so WMG stays on universal providers.

## Links

The tracker opens from its home page and reads no number from its address, so the library reads
no link.
