# Kunzendorf Spedition

Kunzendorf Spedition parcels use enabled universal providers. There is no dedicated adapter.

Kunzendorf Spedition GmbH, "die fixen Kunzendorfer", is a family forwarder from Berlin-Neukölln
with a second site in Ludwigsburg. It carries general cargo through several groupage networks, as
well as part and full loads. Its site is kunzendorf-spedition.de, and its tracker is on
diefixenkunzendorfer.de.

## Numbers

Its tracker takes a shipment number of up to eight characters or a package number of 20
characters in the NVE (SSCC) form. Short numbers fit many carriers, the NVE form is shared by
every forwarder that labels with it, and no public page shows a number, so there is no rule.

## Why there is no adapter

Its tracker posts the number to a script that checks it, then fetches the history, and can ask
for the recipient's postcode before showing details. No public number is known to see a found
reply.

## Links

The tracker page can be filled from its address, but the parameter it reads is not public, so no
link names it.
