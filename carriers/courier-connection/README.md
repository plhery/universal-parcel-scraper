# The Courier Connection

The Courier Connection shipments use enabled universal providers. There is no dedicated adapter.

The Courier Connection delivers parcels and same-day courier jobs in the Mid-Atlantic and the Southeast.

## Numbers

Quick Track takes the courier's order or reference number. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker is a CXT Xcelerator client portal whose guest Quick Track posts the number with a key the courier
gives. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
