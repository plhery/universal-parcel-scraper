# World Courier

World Courier parcels use enabled universal providers. There is no dedicated adapter.

World Courier, part of Cencora, carries medicines and clinical-trial material worldwide. Its site is
worldcourier.com.

## Numbers

Its tracking form takes a shipment number of up to 15 digits. Digits alone match many other
carriers' numbers, so there is no rule.

## Why there is no adapter

Its tracking page finds a shipment by its number and pickup date. With no public number to check its
replies against, there is no adapter.

## Links

The tracking page needs the pickup date beside the number, so there is no link.
