# AirRoad

AirRoad parcels use enabled universal providers. There is no dedicated adapter.

AirRoad is an Australian express road freight carrier, majority owned by Senko since 2021. Its
site is airroad.com.au.

## Numbers

Its consignment notes have no published layout, and no public one has been found, so there is
no rule.

## Why there is no adapter

Its Quick Track page reads an open JSON lookup on my.airroad.com.au without a key, but no public
consignment note has been found to check a found reply with.

## Links

The Quick Track page reads numbers from a form and opens no per-consignment page, so the
catalog sends people to it.
