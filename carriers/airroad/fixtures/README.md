# Fixtures

Replies of `my.airroad.com.au/api/QuickTrack/<number>`, the lookup AirRoad's Quick Track page reads.

- `delivered.json`: the reply for the first public sample in [`numbers.json`](../numbers.json), a delivered
  consignment, without its status text: once a consignment is delivered, that text names who took the goods.
- `not-found.json`: the reply, with HTTP 404, for an invented number.
