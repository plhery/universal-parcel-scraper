Replies of MEITONGDA's Hualei tracker. `delivered.json` is the live answer for the public sample
from a tracking directory's MEITONGDA page, re-encoded as UTF-8 with the account and signatory
fields blanked and the shipper's reference and invoice number zeroed. `no-track.json` and
`page-unknown.html` are the live answers for `ZZ0000000000ZZ`, a string in no shape the tracker
issues.
