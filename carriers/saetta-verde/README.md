# Saetta Verde

Saetta Verde shipments use enabled universal providers. There is no dedicated adapter.

Saetta Verde, an association in Lugano, delivers by bike in the city and gives work to people returning to the
labour market; national legs travel with swissconnect.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The order tracking box on its PinkPost client portal posts the number back to the portal. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
