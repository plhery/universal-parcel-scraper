# Fixtures

Pages of Jamaica Post's Ja Mail tracker, kept as served.

- `form.html`: the form page `track-status.php`, with its CSRF token replaced by a synthetic one.
- `registered.html`: the result page for the public sample in `numbers.json`: registered mail handed on to the Half
  Way Tree post office.
- `not-found.html`: the result page's notice for a code the tracker holds nothing for.
