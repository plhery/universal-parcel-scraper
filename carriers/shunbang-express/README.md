# ShunBang Express

ShunBang Express parcels use enabled universal providers. There is no dedicated adapter.

ShunBang Express (顺邦科技物流) is the parcel line of the Shenzhen cross-border group KJY (跨境翼),
running express and registered lines from China to the United Kingdom, Germany, Australia and the
United States and handing parcels to local carriers. Its site is shunbang.vip.

## Numbers

No public page shows a ShunBang number, so there is no rule.

## Why there is no adapter

Its tracker on tracking.kjy.com answers plain HTTP only, with HTML, and needs a small code derived
from the number alongside it. An unknown number gets a not-found page. No public number is known to
see a found reply.

## Links

The tracker is HTTP only, so the catalog opens the brand site, which links it.
