`found-*.html` are the pages the website's equipment search opens for public samples in
`numbers.json`, named by the container. `unknown-SMLU9999980.html` is its page for an invented
container it holds no record of, and `notfound-SMLU1234567.html` for an invented container whose
record it shows with its notice that it has no information. Each page keeps its title, the search
form and the result card; the rest of the WordPress page is cut. The tests edit them for the cases
no sample shows.
