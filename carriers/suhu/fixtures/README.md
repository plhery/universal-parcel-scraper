# Fixtures

`home-page.html` is the home page cut down to the tracking form and the inline settings its script
reads, with the nonce it sends. `in-transit.json` follows the reply of the tracking plugin's
WordPress action for a parcel handed to its line in Germany: the order, the line's number, the
destination's code and the scans newest first, with the line breaks some wordings end in.
`not-found.json` is the answer for a number the tracker does not know.

Numbers, nonces and clocks are invented.
