Replies of Sunson's Hualei tracker. `track.json` is the live answer for the public sample from
TrackShip's Sunson page, re-encoded as UTF-8 with the account and signatory fields blanked and the
account code in the invoice number and the shipper's reference zeroed. `no-track.json` and
`page-unknown.html` are the live answers for `ZZQX00000000000`, a string in no shape the tracker
issues.
