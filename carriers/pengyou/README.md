# Pengyou

Pengyou parcels use enabled universal providers. There is no dedicated adapter.

Pengyou is Shenzhen Pengyou Supply Chain (深圳市捧友供应链有限公司), a Shenzhen forwarder with air
express lines to Europe and North America, whose site is szpy56.com. The site sends visitors to
17TRACK to track a parcel.

## Numbers

No public source shows a whole Pengyou number. A parcel a universal provider files under Pengyou has
three letters, nine digits and `PY`, so a low rule suggests Pengyou for that layout; the corpus
holds a made-up number in that shape. The letters before the digits may stand for a channel or a
shipper, so the rule stays low.

## Tracker

The site also links a tracker on its own tenant of the Hualei (华磊) forwarder platform, at
`120.77.149.241:8082`, which answers the platform's interface as
[BYHD's](../byhd/README.md) does. Hualei tenants write a whole timeline ahead and reveal its rows as
their clocks pass; universal providers relay those rows as scans. The interface gives the time each
row was written, so a dedicated adapter on the shared client could hold back a forecast.
