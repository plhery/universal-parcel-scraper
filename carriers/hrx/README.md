# HRX

HRX parcels use enabled universal providers. There is no dedicated adapter.

HRX is a Finnish and Baltic road express group with companies in Finland, Estonia, Latvia,
Lithuania, Poland and Sweden. Besides road freight it sells HRX E-com Parcel, delivery to
lockers, pickup points and doors across the EU, often by local partners. Its sites are hrx.eu and
the country sites, hrx.lv among them.

## Numbers

No public parcel or freight number has been found; its plugins' documentation shows only
placeholders. There is no rule.

## Why there is no adapter

The E-com Parcel tracker on wop.hrx.eu reads an open JSON lookup, but no public number has been
found to check a found reply with. The freight tracker is a posted form.

## Links

The E-com Parcel tracker's address carries the number in its path.
