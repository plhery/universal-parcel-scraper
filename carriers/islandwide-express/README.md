# Islandwide Express

Islandwide Express parcels use enabled universal providers. There is no dedicated adapter.

Islandwide Express (PJ Rosaly Enterprises) is a Puerto Rico courier with terminals across the
island. Its site is islandwide.com.

## Numbers

The only public numbers are fourteen digits from 2013 to 2016, a length many carriers share, and
its current layout is unknown, so there is no rule.

## Why there is no adapter

Its tracker reads an open JSON action with the page's anonymous tokens, but no current public
number has been found to check a found reply with.

## Links

The tracking page opens a number from its `TrackingNumber` parameter.
