# Jet Delivery

Jet Delivery shipments use enabled universal providers. There is no dedicated adapter.

Jet Delivery carries same-day courier jobs and freight in California and across the US.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The public page shows the basic status; the details need a customer login. With no public number to check the tracker's replies against, there is no adapter.

## Links

`jetdelivery.com/track/?idx=<number>` opens one shipment, as the page's own search description says.
