# Goodmaji

Goodmaji parcels use enabled universal providers. There is no dedicated adapter.

Goodmaji (好馬吉) is a Taipei cross-border e-commerce carrier shipping Taiwanese shops' orders to
Malaysia, Singapore, Hong Kong, Macau, Vietnam and Thailand. Its site is goodmaji.com.

## Numbers

No public page shows a Goodmaji waybill number, so there is no rule.

## Why there is no adapter

Its tracker is a form post without a session or CAPTCHA that renders results as HTML, but no
public number is known to see a found reply.

## Links

Its tracker takes numbers in a form, so no portal link is published.
