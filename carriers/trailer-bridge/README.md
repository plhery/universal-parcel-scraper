# Trailer Bridge

Trailer Bridge shipments use enabled universal providers. There is no dedicated adapter.

Trailer Bridge, from Jacksonville, Florida, ships trailers, containers and vehicles between the mainland, Puerto Rico
and the US Virgin Islands.

## Numbers

QuickTrack takes a booking number, an equipment number or the last eight characters of a VIN, so there is no rule.

## Why there is no adapter

QuickTrack posts the reference. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
