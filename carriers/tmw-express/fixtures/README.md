`synthetic-order.json` is synthetic: no public page shows a TMW Express order number. It follows the reply
model the tracker's own script reads (`airStepList` with `stepno`, `steptype` and `steptime`;
`logisticsrecordList` with `context`, `ftime` and `time`), with the step wordings of that script, invented
clocks, and courier rows, people and phone numbers written for the tests.

`not-found.json` is the service's reply to a number it does not have.
