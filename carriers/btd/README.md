# BTD

BTD parcels use enabled universal providers. There is no dedicated adapter.

BTD (宝通达, Shenzhen Bao Tongda International Freight Forwarding) ships Amazon FBA freight and
small-parcel lines from China to North America and Europe, with its own warehouse in the United
States. Its site is btdair.com.

## Numbers

Its site gives no number layout and no public page shows a BTD number, so there is no rule.

## Why there is no adapter

Its tracker answers plain HTTP only, on a bare IP address, and requires a slider CAPTCHA before
it looks a number up.

## Links

The tracker is HTTP only, so the catalog opens the site.
