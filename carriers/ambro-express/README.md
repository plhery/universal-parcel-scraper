# Ambro Express

Ambro Express parcels use enabled universal providers. There is no dedicated adapter yet.

Ambro Express is a Polish courier for oversized parcels such as furniture and appliances,
delivering in Poland and to Germany, Austria, Czechia and Slovakia.

## Numbers

Its tracker takes exactly thirteen characters, but no public page shows a number, so no rule
names it.

## Tracker

The tracking page posts the number to itself and gets JSON back, without a postcode or CAPTCHA.

## Links

The tracking page opens the number after `#` in its address.
