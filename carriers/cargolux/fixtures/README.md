# Fixtures

Replies of the tracker's service to `GET /api/track/awbs/?numbers=<waybill>`, as it sends them.

- `awb-172-87779521.json`: the public sample in `numbers.json`, a consolidation flown from
  Luxembourg to Johannesburg, received there in two parts and delivered.
- `not-found.json`: the answer for an invented waybill whose check digit holds.
