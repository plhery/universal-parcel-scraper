# XYL-Ships

XYL-Ships parcels use enabled universal providers. There is no dedicated adapter.

XYL-Ships is a Chinese forwarder whose site is xylships.com. 17TRACK lists it as FXYL, the name
the catalog keeps as an alias. 17TRACK's XYL is another company, Xingyuan International Logistics,
which the catalog files as [XYL](../xyl/README.md).

## Numbers

XYL-Ships publishes no number format and no public page shows one of its numbers, so there is
no rule.

## Why there is no adapter

Its site renders in the browser, and an address carrying a number (`/tracking?trackNo=`) opens
the home page. 17TRACK and Postal Ninja copy its history.
