# Royal Gibraltar Post Office

Royal Gibraltar Post Office parcels use enabled universal providers. There is no dedicated adapter.

The Royal Gibraltar Post Office is Gibraltar's postal operator. Its site is post.gi.

## Numbers

Its items carry UPU S10 numbers ending `GI`, which postal detection reads. No public page shows one,
so there is no rule of its own.

## Why there is no adapter

Its track page embeds the UPU's hosted tracker, which asks for an image CAPTCHA.

## Links

Its tracker has no address for a single number, so no link names it.
