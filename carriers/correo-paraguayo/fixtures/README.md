# Fixtures

Replies of Correo Paraguayo's JSON endpoint `/sen/?id_envio=<number>`, kept as served apart from the
addressee's name, which is replaced with `SAMPLE PERSON`.

- `planillado.json`: the public sample in `numbers.json`: a registered item from Malaysia that entered Correo
  Paraguayo's network and went on a dispatch sheet to Salto del Guairá's office.
- `not-found.json`: the message for a code the endpoint holds nothing for.
