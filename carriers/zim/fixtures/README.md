# Fixtures

`tracking-*.json` are ZIM's replies to its tracking page's lookup for the public samples in
`numbers.json`, each named after the number looked up and indented. `tracking-TCNU2975217.json` is
the reply for the container of the second sample's bill, and `tracking-GOSU1029960.json` the reply
for a container of Gold Star Line's public samples, which ZIM says Gold Star Line holds. The tests
edit them for the cases no sample shows.
