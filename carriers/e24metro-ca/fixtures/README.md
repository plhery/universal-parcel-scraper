# Fixtures

Replies of FarEye Canada's tracker, as E24's public search page asks it.

- `search.txt`: the reply of `get_universal_tracking_url` for the public sample in `numbers.json`, its
  tracking page in each language.
- `delivered.json`: the reply of `get_last_mile_and_status_details` for that sample's first page, in
  English, with the delivery photos' addresses taken out of the feedback block.
- `delivered-bilingual.json`: the statuses of the same reply for the sample's bilingual page.
- `not-found.txt`: the search's reply for a synthetic number of E24's shape.

The replies name no person and give no phone number.
