Replies of DANX's `GET FastTrackService.asmx/GetShipmentDetails`. `label-KU00001.json` is the reply
to the public sample in [`numbers.json`](../numbers.json), with the sender's and receiver's names
and addresses, the signer, the note and the sender's account code replaced. `not-found.json` is the
answer for a number DANX has no shipment under. The tests derive their other shipments from the
sample with invented numbers.
