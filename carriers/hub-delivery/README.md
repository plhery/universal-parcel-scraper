# HUB Delivery

HUB Delivery parcels use enabled universal providers. There is no dedicated adapter.

HUB Delivery Incorporated is a regional courier and cartage carrier in Wilmington, Massachusetts,
serving New England. It is not Hub Group's final-mile network. Its site is hubdelivery.com.
17TRACK spells its name "HUB Delivery Incorporarted", so that spelling is an alias.

## Numbers

Its tracker finds a shipment by its package id, PRO number or bill of lading. No public page shows
one, so there is no rule.

## Why there is no adapter

Its tracking page's script asks a JSON service on `podtracking.hubdelivery.com`. With no public
number to check its replies against, there is no adapter.

## Links

The tracking page opens numbers from its `search` parameter.
