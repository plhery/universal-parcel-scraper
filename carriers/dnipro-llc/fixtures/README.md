# Fixtures

Replies of `POST dniprollc.com/wp-json/dnipro-tracking/v1/lookup`, the lookup Dnipro LLC's tracking
page posts the number to, asked in English.

- `created.json`: the whole reply for the first public sample in [`numbers.json`](../numbers.json), a
  parcel with its creation event.
- `not-found.json`: the reply, with HTTP 200, for an invented number.
