# Avis Logistics

Avis Logistics parcels use enabled universal providers. There is no dedicated adapter yet.

Avis Logistics is an Almaty courier for documents and cargo across Kazakhstan, with a Moscow
branch.

## Numbers

Waybills are thirteen zero-padded digits, a length many carriers share, so no rule names it.

## Tracker

The site's tracking form needs no login or CAPTCHA; no public waybill it answers was found.

## Links

The home page reads the waybill from its `trace` parameter and looks it up.
