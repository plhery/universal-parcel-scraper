# APD

APD parcels use enabled universal providers. There is no dedicated adapter.

APD, or Adelaide Parcel Delivery, is South Australia's oldest parcel delivery company. From Dudley
Park in Adelaide it runs same-day couriers, overnight parcels, taxi trucks and freight. Its site is
apdparcel.com.au.

## Numbers

Public examples are R, seven digits and a letter. Its tracker also takes ticket and job numbers.
Only an aggregator's examples show the layout, so there is no rule.

## Why there is no adapter

Its tracker runs on Hub Systems software. The page's script posts the search key to `index.php`,
which redirects to the result.

## Links

The tracker posts the number, so no address opens one parcel.
