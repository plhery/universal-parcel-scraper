# Fixtures

Replies of `POST cms.4aexpress.com/Query/TrackAwbNoQuery.aspx/ShowAwbNoQuery`, the page method 4A Express's
tracking page calls.

- `delivered.json`: the reply for the public sample in [`numbers.json`](../numbers.json), a delivered shipment,
  with the name of whoever received it replaced by a placeholder.
- `empty.json`: the reply for an invented number, an empty grid.
