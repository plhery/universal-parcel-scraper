# JET DP

JET DP parcels use enabled universal providers. There is no dedicated adapter.

JET DP is a postal operator in Warsaw, Poland, for parcels from Poland to Ukraine. Senders leave
parcels in InPost lockers; JET DP gathers them at its warehouse in Tomaszów Lubelski and hands them
to Ukrposhta, which delivers them in Ukraine. Its site is jet-dp.pl.

## Numbers

No public page shows a JET DP number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows a parcel's origin and destination city and a dated list of its events. With
no public number to check its replies against, there is no adapter.

## Links

Its tracking page sends a number from a script and reads none from its address, so no address opens
one item.
