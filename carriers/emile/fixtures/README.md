# Fixtures

`delivered.json` is synthetic ParcelsApp history for a parcel a consolidator hands to
Emile, with Emile's scans relayed under the consolidator's name. Places, clocks and the
number are invented; the provider envelope, carrier labels and Emile's wordings keep the
response shape.

`delivered.xml` and `not-found.xml` match the anonymous XML service's response
structure with synthetic identifiers, places, clocks and recipient placeholders.
The operation code differs from a scan's sequential position in the history.
