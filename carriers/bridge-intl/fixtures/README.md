# Fixtures

Replies of `www.bri-ems.com/getorder.php`, the lookup Bridge Intl's query page sends.

- `customs.html`: the reply for the public sample in `numbers.json`, a parcel from Perth in customs clearance in
  China and handed to a Chinese courier. The recipient's address keeps its province and city only.
- `not-found.html`: the reply for a synthetic number of the sample's shape.

The replies name no person and give no phone number.
