# SM Express

SM Express parcels use enabled universal providers. There is no dedicated adapter.

SM Express Cargo is a New Delhi courier and cargo firm founded in 2006, with booking counters
across India. Its site is smexpress.in.

## Numbers

Its site gives no number layout and no public page shows an SM Express number, so there is no rule.

## Why there is no adapter

Its tracking page posts the number as `LRNo` and answers with HTML, without a session or CAPTCHA.
An unknown number gets a notice that no data was found. No public number is known to see a found
reply.

## Links

The tracking page takes the number only in its form, so no address opens one parcel.
