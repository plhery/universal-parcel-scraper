# Csomagpiac

Csomagpiac parcels use enabled universal providers. There is no dedicated adapter.

Csomagpiac Kft. in Gödöllő delivers parcels, large items and pallets with its own couriers, and
sends shipments through DPD, Magyar Posta and Foxpost. Its site is csomagpiac.hu.

## Numbers

Its tracker takes Csomagpiac's own ids and its partners' numbers, which belong to those
carriers. No public page shows a Csomagpiac id, so there is no rule.

## Why there is no adapter

With no public number to check its tracker's replies against, there is no adapter.

## Links

The tracking page opens numbers from its `ident` parameter.
