# Instapack

Instapack parcels use enabled universal providers. There is no dedicated adapter yet.

Instapack, run by Immediate Delivery S.L., delivers same-day and next-day parcels with its own
drivers in Spanish cities and Paris.

## Numbers

The only codes on public pages are fifteen-digit order ids from 2018, a length many carriers
share, and the current layout is unknown, so no rule names it.

## Tracker

The tracking form needs no login or CAPTCHA. A found code redirects to a signed result page that
expires after a week, so there is no lasting link per parcel, and the page shows the
recipient's address and the driver's phone.
