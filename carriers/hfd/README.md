# HFD

HFD parcels use enabled universal providers. There is no dedicated adapter.

HFD is an Israeli courier and logistics company. Its ePost network of pickup points delivers
e-commerce parcels, many from abroad, and its site is hfd.co.il.

## Why there is no adapter

HFD's tracker takes an access code sent by text message or email, or a shipment number with the
recipient's phone number. Its sites answer requests from outside Israel with a firewall block.
HFD's shipment numbers are eight digits, which many carriers share, so no rule names HFD.
