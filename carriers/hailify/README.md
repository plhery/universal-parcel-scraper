# Hailify

Hailify shipments use enabled universal providers. There is no dedicated adapter.

Hailify delivers online orders the same or the next day with drivers from partner fleets across US cities.

## Numbers

Its numbers are digits. No public page shows one, so there is no rule.

## Why there is no adapter

The tracking page asks Hailify's API for the order. With no public number to check the tracker's replies against, there is no adapter.

## Links

The page reads the number as the whole query of `tracking.hailify.liota.ai/track?<number>`, which no link rule can
name, so only the template uses it.
