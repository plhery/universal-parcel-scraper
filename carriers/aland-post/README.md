# Åland Post

Åland Post parcels use enabled universal providers. There is no dedicated adapter.

Åland Post is the postal operator of the Åland Islands. Its site is alandpost.ax.

## Numbers

Its items carry UPU S10 numbers ending `AX`, which postal detection reads. No public page shows one,
so there is no rule of its own.

## Why there is no adapter

Its tracker reads the number from its address without a session or CAPTCHA, shows events on Åland only and says
when a shipment is not found. No public number is known to see a found reply.

## Links

The English tracking page opens numbers from its `shipmentid` parameter.
