# Aiolos Courier

Aiolos Courier parcels use enabled universal providers. There is no dedicated adapter.

Aiolos Courier is a courier in Peristeri, Attica, Greece, with its own vans and motorbikes and
agents across the country. Its site is aioloscourier.gr.

## Numbers

Its tracking form takes a shipment code of 5 to 15 characters. No public page shows a whole number,
so there is no rule.

## Why there is no adapter

Its tracking page finds a shipment by its code. With no public number to check its replies against,
there is no adapter.

## Links

The tracking page opens numbers from its `shipping_num` parameter.
