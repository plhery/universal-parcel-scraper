# Bonds Couriers

Bonds Couriers parcels use enabled universal providers. There is no dedicated adapter.

Bonds Couriers is a Sydney courier group running same-day and overnight jobs in Australia's main cities. Its
site is bondscouriers.com.au.

## Numbers

Its jobs carry a seven-digit job ID and a five-digit job number. Seven digits are shared by other carriers and no
public page shows one, so there is no rule.

## Why there is no adapter

Its tracker needs the job's date with the number.

## Links

Its tracker has no address for a single number, so no link names it.
