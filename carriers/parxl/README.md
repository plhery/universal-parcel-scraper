# Parxl

Parxl parcels use enabled universal providers. There is no dedicated adapter.

Parxl is Singapore Airlines' cross-border e-commerce service, flying parcels from Singapore and handing them
to a delivery carrier in the destination country. Its site is parxl.com.

## Numbers

No public page shows a Parxl number, so there is no rule.

## Why there is no adapter

Its tracking page reads an open JSON API without a session or CAPTCHA, which answers an unknown number with
HTTP 403 and a not-found message. No public number is known to see a found reply.

## Links

The tracking page takes the number in its path.
