# Cheetah Delivery

Cheetah Delivery parcels use enabled universal providers. There is no dedicated adapter.

Cheetah Delivery (צ'יטה שליחויות, Chita) is an Israeli courier with a network of pickup points
that delivers many parcels from AliExpress. Its site is chitadelivery.co.il.

## Why there is no adapter

Its tracker opens from a link sent by text message, whose access code is the only key it reads,
or takes a shipment number with the recipient's phone number. The tracker answers requests from
outside Israel with a block. Its shipment numbers are eight digits, so no rule names it.
