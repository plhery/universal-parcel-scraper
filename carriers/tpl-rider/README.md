# Rider

Rider parcels use enabled universal providers. There is no dedicated adapter.

Rider, a company of Pakistan's TPL group based in Karachi, delivers online shops' orders to their
customers in Pakistan. Its tracker, track.withrider.com, answers no network, and withrider.com
shows a domain host's placeholder page.

## Numbers

Its tracker took consignment numbers that start with WR or DZ and have at least seven more letters
or digits. No public number is known, so there is no rule.

## Why there is no adapter

The tracker answers no network. It asked an open JSON service without a session, which answered
an unknown number with not found, and no public number showed a known parcel's reply.

## Links

Tracking links carried the number after `#/track/` in the tracker's address, which the library
reads. The catalog links no page while the tracker answers no network.
