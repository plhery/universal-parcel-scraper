# Velokurier St.Gallen

Velokurier St.Gallen shipments use enabled universal providers. There is no dedicated adapter.

Velokurier St.Gallen, run by die Fliege, delivers by bike in St. Gallen; national legs travel with swissconnect.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

"Track Auftrag" on its KurierZentrale client portal posts the number back to the portal, as Veloblitz's does.
With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
