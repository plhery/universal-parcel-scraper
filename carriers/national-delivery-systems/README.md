# National Delivery Systems

National Delivery Systems parcels use enabled universal providers. There is no dedicated adapter.

National Delivery Systems, Inc. (NDS) is a regional LTL, cartage and pool distribution carrier based
in Columbia, Maryland, with terminals along the East Coast. Its site is national-delivery.com.

## Numbers

Its trace finds a shipment by its NDS bill number, a bill of lading, a reference or a purchase
order. No public page shows one, so there is no rule.

## Why there is no adapter

The Track Order form on its site posts to its Trimble TMW web trace, `ndsweb.tmwcloud.com`, which
answers a form with the trace type and the number. With no public number to check its replies
against, there is no adapter. The catalog links to the trace page, which serves the same form.

## Links

The trace takes the number in a posted form, so no address opens one shipment and the library
reads no link.
