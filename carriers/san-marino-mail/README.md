# San Marino Mail

San Marino Mail shipments use enabled universal providers. There is no dedicated adapter.

San Marino Mail Italia is a private mail and parcel operator for businesses and online shops in Italy and Europe.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker is a public web application that reads San Marino Mail's API. With no public number to check the tracker's replies against, there is no adapter.

## Links

`tracking.sanmarinomail.it/area/search/<number>` opens one shipment; the application keeps the number in its path.
