# Johnny Air Cargo

Johnny Air Cargo shipments use enabled universal providers. There is no dedicated adapter.

Johnny Air Cargo ships by air and sea from Woodside, New York, to the Philippines, with offices in Makati, Cebu
and Davao.

## Numbers

The tracker takes a tracking number, an invoice or an air waybill. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker is a Vaadin application that answers through its own session. With no public number to check its
replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
