# Prisma Courier

Prisma Courier parcels use enabled universal providers. There is no dedicated adapter.

Prisma Courier (Prisma Service) is a courier in Palaio Faliro, Athens, Greece, that delivers in
Athens and across the country, and abroad with UPS and DHL. Its site is prismacourier.gr.

## Numbers

No public page shows a Prisma Courier number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page takes a shipment code through a form that posts it. With no public number to check
its replies against, there is no adapter.

## Links

Its tracking page takes numbers only through a form that posts them, so no address opens one item.
