# HSD Express

HSD Express parcels use enabled universal providers. There is no dedicated adapter.

HSD Express (鸿速达国际物流, HongSuDa) is a Shenzhen forwarder founded in 2012, running
cross-border parcel lines from China. Its site is hsd-express.cn. Another Chinese line, 寰世达,
has been listed under the same English name; its numbers are not HSD Express's.

## Numbers

No public page shows an HSD Express number, so there is no rule.

## Why there is no adapter

The home page's tracking box posts the numbers to an open JSON endpoint without a session or
CAPTCHA, and its Hualei client site has the usual waybill lookup. No public number is known to
see a found reply.

## Links

The tracking box takes the number in its form, so no address opens one parcel.
