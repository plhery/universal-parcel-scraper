# Diakon Logistics

Diakon Logistics shipments use enabled universal providers. There is no dedicated adapter.

Diakon Logistics arranges furniture and appliance home delivery for retailers with contractor crews under its brand.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

"Track Order" asks the order number and the delivery ZIP code, without an account. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
