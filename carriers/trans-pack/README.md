# Trans-Pack

Trans-Pack parcels use enabled universal providers. There is no dedicated adapter.

Trans-Pack Logisztika Kft. is a parcel and pallet carrier in Hungary that delivers on the next
working day from its own depots. Its site is trans-pack.hu.

## Numbers

Its tracking page asks for the 6-digit parcel number in the posting confirmation. Six digits
are too common for a rule.

## Why there is no adapter

With no public number to check its tracker's replies against, there is no adapter.

## Links

The tracking page opens numbers from its `id` parameter.
