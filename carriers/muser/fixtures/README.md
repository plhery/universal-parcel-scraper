# Fixtures

The replies are `Service.ashx`'s JSONP for one number, as the adapter asks it.

- `out-for-delivery.txt` is synthetic, in the shape of a live reply: a made-up parcel flown from
  Hong Kong to the United States, where the delivering network took it out for delivery. Every
  scan states China's offset; the delivering network's leave the place empty and end with a town
  and ZIP Code.
- `not-found.txt` is the tracker's answer for a made-up number.
