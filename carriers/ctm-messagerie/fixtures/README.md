# Fixtures

Replies of `POST ctm-messagerie.ma/fr/suivi-du-colis`, CTM Messagerie's tracking page, trimmed to the page's
title and its result section.

- `delivered.html`: the reply for the public sample in [`numbers.json`](../numbers.json), a delivered parcel, with
  the recipient's name replaced by a placeholder. The section keeps the page's commented-out sample rows.
- `not-found.html`: the reply for an invented number.
