# JAS-FBG

JAS-FBG shipments use enabled universal providers. There is no dedicated adapter.

JAS-FBG, from Katowice, distributes general cargo and pallets across Poland and forwards road, air and sea freight.

## Numbers

Its help pages describe its waybill numbers as ten digits, a shape many carriers share, so there is no rule.

## Why there is no adapter

The public waybill page posts the number back to itself. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
