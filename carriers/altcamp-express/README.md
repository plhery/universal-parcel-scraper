# Altcamp Express

Altcamp Express parcels use enabled universal providers. There is no dedicated adapter.

Altcamp Express is an urgent courier in Valls, Tarragona, for national, international and direct
deliveries.

## Numbers

No public page shows an Altcamp Express number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `valls.factapp.es`. No public
number is known to check its replies against.

## Links

The company's site links the tracker over HTTP; the catalog uses its HTTPS address.
`/IRIS/Seguimiento?s=<number>` opens one shipment, so the catalog links each number there. Each IRIS
tenant keeps its own shipments, so links are read only on the company's tenant.
