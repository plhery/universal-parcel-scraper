Synthetic replies of the app's guest tracking service. The number, clocks, places, names,
reasons and the sender reference are invented; the envelopes, field names, trace codes and
activity wording follow live GetItemSummary and GetEvents replies. `unknown.json` is the
empty list An Post gives an unknown or expired number, `key-refused.json` API Management's
answer to a refused key, `quota-spent.json` its documented answer to a spent call quota,
`route-missing.json` its answer to an unknown operation and `firewall.html` the gateway
firewall's block page.
