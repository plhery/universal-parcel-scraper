Pages of MBE Spain's tracker as a browser renders them, cut to the section between the site's
menus and its footer. `delivered.html` is the page for the public sample in
[`numbers.json`](../numbers.json), a UPS parcel delivered near Madrid; the signer's name is
replaced with `FIRMANTE`. `not-found.html` is the reply for an invented code and
`access-denied.html` Akamai's refusal of an HTTP client.
