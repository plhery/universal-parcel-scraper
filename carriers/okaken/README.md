# Okayamaken Freight Transportation

Okayamaken Freight Transportation parcels use enabled universal providers. There is no dedicated adapter.

Okayamaken Freight Transportation (岡山県貨物運送, Okaken) is a Japanese less-than-truckload carrier
based in Okayama. Its site is okaken.co.jp.

## Numbers

Its inquiry numbers are ten digits, a length many carriers share, so there is no rule.

## Why there is no adapter

Its tracker answers a posted form without a session, but it keeps about six months of history,
and no current public number has been found to check a found reply with.

## Links

The tracker reads numbers from a form and opens no per-number page, so the catalog sends people
to it.
