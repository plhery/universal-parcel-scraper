# Depo

Depo parcels use enabled universal providers. There is no dedicated adapter yet.

Depo is Mediaprint-Kapa Pressegrosso's network of pickup points for e-shop parcels in Slovakia,
with home delivery by its own couriers.

## Numbers

The only public number is thirteen digits, a length many carriers share, so no rule names it.

## Tracker

The tracking page checks an invisible CAPTCHA on every lookup.

## Links

The tracking page reads the number from its `number` parameter.
