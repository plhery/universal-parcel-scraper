# Mail Runner

Mail Runner items use enabled universal providers. There is no dedicated adapter.

Mail Runner of Reggio Calabria is a private post for letters, parcels and notices, with offices in
the city and in Catona. It is on the Italian Ministry of Enterprises' register of postal operators.

## Numbers

No public page shows a number or its layout, so there is no rule.

## Why there is no adapter

The home page's "Tracciatura Spedizione" form posts the number to the same page with a WordPress
nonce. With no public number to check its replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one item.
