# Aloha Air Cargo

Aloha Air Cargo shipments use enabled universal providers. There is no dedicated adapter.

Aloha Air Cargo, from Honolulu, flies freight between the Hawaiian islands and to the West Coast. It is not the
catalog's Aloha Freight.

## Numbers

Its air waybills are the prefix 687 and eight digits. No public page shows one, so there is no rule.

## Why there is no adapter

The tracking page posts the air waybill. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
