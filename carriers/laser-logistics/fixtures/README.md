# Fixtures

Each fixture is Laser Logistics's page for one waybill, `parcel-tracking/?waybillnumber=`, cut
to its tracking section: the comment with the service's reply, the form, and the notice or the
tables. The site's menus, footer, scripts and styles are left out.

`delivered.html` is the reply for the public example in [`numbers.json`](../numbers.json), a
road parcel from Johannesburg's hub delivered in Durban's area. `not-found.html` is the reply for
a number of the same shape that the tracker does not know.
