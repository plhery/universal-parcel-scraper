# messenger Transport + Logistik

messenger Transport + Logistik shipments use enabled universal providers. There is no dedicated adapter.

messenger Transport + Logistik is a courier in Berlin and Potsdam for city, overnight and national deliveries; a sister
company serves Leipzig, Dresden and Munich. It is not the Czech Messenger.

## Numbers

The tracker takes a shipment, package or order number. No public page shows one, so there is no rule.

## Why there is no adapter

Each lookup posts the number, and optionally the destination postcode, with an hCaptcha answer. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
