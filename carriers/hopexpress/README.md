# Hopexpress

Hopexpress parcels use enabled universal providers. There is no dedicated adapter.

Hopexpress, HOPEXPRESS DOO of Belgrade, is a Serbian courier that delivers parcels within
Belgrade only.

## Numbers

Its tracking page takes a shipment code of twelve characters; the field's example is `CE` and ten
digits. No public page shows a real code, so there is no rule.

## Why there is no adapter

The tracking form posts the code to the page, which shows the shipment's status history and a
link to its fiscal receipt. With no public code to check its replies against, there is no
adapter.

## Links

Its tracker takes codes only through a form that posts them, so no address opens one shipment.
