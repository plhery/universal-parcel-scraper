# TheLorry

TheLorry parcels use enabled universal providers. There is no dedicated adapter.

TheLorry is a Malaysian lorry-hire and moving platform whose Bulky Express service delivers bulky
parcels for Shopee and Lazada sellers. It also operates in Singapore and Indonesia. Its site is
thelorry.com.

## Numbers

`thelorry-1` suggests `TLZ` and seven digits at low confidence, the layout its tracker shows as
its input example; no public parcel number is known. Australia Post's ten-character consignment
rule shares the shape.

## Why there is no adapter

Its trackers read a JSON API without a session, but no public parcel number is known to confirm
an answer.

## Links

Both trackers open a parcel number from their path.
