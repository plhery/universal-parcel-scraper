# Diamond Line Delivery Systems

Diamond Line Delivery Systems shipments use enabled universal providers. There is no dedicated adapter.

Diamond Line Delivery Systems, from Meridian, Idaho, carries less-than-truckload freight in Idaho and the
neighbouring Northwest and Mountain states.

## Numbers

The tracker takes a PRO number. No public page shows one, so there is no rule.

## Why there is no adapter

The tracking widget posts the PRO number to the site's API. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
