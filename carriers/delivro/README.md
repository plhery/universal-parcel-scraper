# Délivro

Délivro parcels use enabled universal providers. There is no dedicated adapter.

Délivro is a Quebec City courier delivering parcels across Quebec. Its site is delivro.com.

## Numbers

No public page shows a Délivro number, so there is no rule.

## Why there is no adapter

Its tracker, hosted on Dispatch Science, reads an open JSON endpoint without a session or CAPTCHA and answers
an unknown number with not found. No public number is known to see a found reply.

## Links

The tracker takes the number in its path.
