# Zadbano

Zadbano shipments use enabled universal providers. There is no dedicated adapter.

Zadbano delivers furniture and large goods at home with carrying in, assembly and installation; Allegro sells it as
its bulky delivery method.

## Numbers

The tracking page takes an order number with the recipient's phone. No public page shows one, so there is no rule.

## Why there is no adapter

Recipients get a personal link; the public page finds a delivery by order number and phone. With no public number to check the tracker's replies against, there is no adapter.

## Links

The personal links carry a token, not the number, so no link rule reads them.
