- `containers-CKCODLC0021206.json` and `containers-CKCOPUS0223497.json`: each bill's containers,
  from `WESSUP411R02`.
- `moves-CKLU3056592.json` and `moves-SEGU2887315.json`: each container's moves, from
  `WESSUP411R03`.
- `not-found.json`: the container list for an invented bill the e-service holds nothing for.

The tests add a synthetic second container, `CKLU3056593`, whose check digit does not match.
