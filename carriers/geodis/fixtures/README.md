# GEODIS fixtures

- `out-for-delivery.json` — the `contenu` block of a shipment out for delivery: an active
  timeline step, two days of scans with agency names, a planned date, a parcel count and weight,
  and the sender, recipient, complementary-information and document blocks. Built to the
  endpoint's shape with a synthetic shipment number. The sender's name is a made-up company;
  every other personal value is a placeholder the privacy test looks for.
