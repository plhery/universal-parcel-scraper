Replies of Commercive Parcel's `GET commerciveparcel.com/api/track?numbers={number}`.
`delivered.json` answers the public example in [`numbers.json`](../numbers.json) as the tracker
gave it; it holds no name, phone or street. `not-found.json` is the answer for a valid number the
tracker has no parcel under, and `invalid.json` the answer for a number that fails its check.
