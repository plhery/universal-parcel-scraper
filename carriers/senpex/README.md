# Senpex

Senpex shipments use enabled universal providers. There is no dedicated adapter.

Senpex delivers on-demand and scheduled last-mile orders for businesses in US and Canadian cities.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker is a web application that keeps the delivery in its path. With no public number to check the tracker's replies against, there is no adapter.

## Links

`web.senpex.com/t2/<number>` opens one delivery.
