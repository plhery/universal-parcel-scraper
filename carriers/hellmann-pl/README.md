# Hellmann Poland

Hellmann Poland shipments use enabled universal providers. There is no dedicated adapter.

Hellmann Worldwide Logistics Polska carries road groupage in Poland and abroad. Its road shipments have their own
numbers and tracker; the Hellmann entry asks only the group's worldwide tracker.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker is a GET form; a search by the customer's order number also needs the postcode. With no public number to check the tracker's replies against, there is no adapter.

## Links

`info.hwl.pl/tt/?searchKey=<number>` opens one shipment.
