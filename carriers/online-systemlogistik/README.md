# ONLINE Systemlogistik

ONLINE Systemlogistik shipments use enabled universal providers. There is no dedicated adapter.

ONLINE Systemlogistik, from Paderborn, is a cooperation of medium-sized German general-cargo hauliers. A partner haulier's consignment travels under the network's numbers and is tracked on this page, so members are not
separate carriers.

## Numbers

The tracker takes the colli's barcode and the destination postcode. No public page shows one, so there is no rule.

## Why there is no adapter

The site refuses plain HTTP clients with a 403 and answers a browser. With no public number to check the tracker's replies against, there is no adapter.

## Links

The form opens `oslnet.de/sendungsverfolgung/?id=<barcode>&postCode=<postcode>`; the link rule reads the barcode.
The catalog's link template takes only the number, so there is none.
