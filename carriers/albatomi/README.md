# Albatomi

Albatomi parcels use enabled universal providers. There is no dedicated adapter.

Albatomi carries parcels between Romania and Italy with its own vehicles, and delivers across
Romania. Its site is albatomi.ro.

## Numbers

No public page shows an Albatomi number or its layout, so there is no rule.

## Why there is no adapter

Its home page tracks an AWB through a form that posts it with a token. With no public number to
check its replies against, there is no adapter.

## Links

The form posts the number with a token, so no address opens one item.
