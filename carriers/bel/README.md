# BEL

BEL parcels use enabled universal providers. There is no dedicated adapter.

BEL (北俄国际, 北俄供应链) runs e-commerce lines from China to Russia, with warehouses in Russia and
hand-offs to Russian Post, CDEK and the marketplaces. Its site is 8256ru.com.

## Numbers

Its site gives no number layout and no public page shows a BEL number, so there is no rule.

## Why there is no adapter

Its tracker is a tenant of the Kingtrans platform, which answers an open XML lookup without a
session or CAPTCHA. No public number is known to see a found reply.

## Links

The Kingtrans tracking page opens the number from its `bills` parameter.
