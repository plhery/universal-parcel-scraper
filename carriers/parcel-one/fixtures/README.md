# Fixtures

Replies of PARCEL.ONE's tracker, `parcel.one/wp-json/parcelone/v1/track`, asked in English with an empty
postcode.

- `delivered.json`: the reply for the public sample in `numbers.json`, a parcel handed at the hub to Liechtenstein
  Post, which delivered it. It names no recipient: the tracker gives none without their postcode.
- `not-found.json`: the reply for a synthetic thirteen-digit number the tracker does not know.
