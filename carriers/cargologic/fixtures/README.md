# Fixtures

Replies of the tracking service to `GET /.servlet/tracking/1.0/?awb=<waybill>`, as it sends them.

- `export.json`: the first public sample in `numbers.json`, an export received at Zurich and flown out.
- `import.json`: the second public sample, an import flown into Zurich, announced and handed to the forwarder.
- `not-found.json`: the 404 answer for an invented waybill whose check digit holds.
