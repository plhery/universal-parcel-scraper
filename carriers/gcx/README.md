# GCX

GCX parcels use enabled universal providers. There is no dedicated adapter.

GCX (Global Courier Express) is an Israeli e-commerce import courier: it clears parcels through customs at
the airport and delivers them across Israel. Its site is gcx.co.il.

## Numbers

No public page shows a GCX number, so there is no rule.

## Why there is no adapter

Its tracker is an ASP.NET form in a frame, and its host did not answer from outside Israel.

## Links

Its tracker has no address for a single number, so no link names it.
