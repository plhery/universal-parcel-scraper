# Fixtures

Tracking pages of MHI's tracker, `www.trackmail.co.uk/?Tracking={number}&command=Track`.

- `delivered.html`: a tracked item from MHI's export facility, handed to a courier abroad and
  delivered after two attempts, with the courier's number and a link to its tracker.
- `untracked.html`: an untracked item with MHI's export scan and the number the destination's
  post gives it.
- `not-found.html`: the page for a number the tracker does not know.

Numbers, places, the courier's link and the page's tokens are invented, and the dates are moved.
