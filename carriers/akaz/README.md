# AKAZ

AKAZ shipments use enabled universal providers. There is no dedicated adapter.

AKAZ ships parcels by air and sea from Choisy-le-Roi, near Paris, to Martinique, Guadeloupe, French Guiana and
La Réunion, for private people and businesses.

## Numbers

The site's own form accepts AK, AKM or AKP followed by 13 letters or digits. No public page shows one of its
numbers, so there is no rule.

## Why there is no adapter

The tracker is a server-rendered WordPress page. With no public number to check the tracker's replies against, there is no adapter.

## Links

`a-kaz.com/suivi/?trackingCode=<number>` opens one parcel.
