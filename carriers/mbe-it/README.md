# MBE Italy

MBE Italy shipments use enabled universal providers. There is no dedicated adapter.

Mail Boxes Etc. Italia runs the franchise network's shipping, packing and printing centres in Italy, where the
network began. Its centres ship with partner couriers under MBE's own tracking code.

## Numbers

No public page shows an MBE Italy tracking code, so there is no rule.

## Why there is no adapter

The site refuses plain HTTP clients with a 403 and answers a browser. Its tracker is the same application as MBE
Spain's. With no public number to check the tracker's replies against, there is no adapter.

## Links

`mbe.it/it/tracking?c=<code>` opens one shipment, as MBE Spain's address does on its own site.
