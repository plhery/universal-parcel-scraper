# PAQLine

PAQLine parcels use enabled universal providers. There is no dedicated adapter.

PAQLine Express Group is a courier in Sangüesa, Navarra, for local, national and international
deliveries. Its IRIS tenant is named after the region.

## Numbers

No public page shows a PAQLine number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `navarra.factapp.es`. No public
number is known to check its replies against.

## Links

The company's site links the tracker. `/IRIS/Seguimiento?s=<number>` opens one shipment, so the
catalog links each number there. Each IRIS tenant keeps its own shipments, so links are read only on
the company's tenant.
