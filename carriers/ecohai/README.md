# Ecohai

Ecohai parcels use enabled universal providers. There is no dedicated adapter.

Ecohai (エコ配), part of CBcloud, is an urban courier based in Tokyo that delivers
nationwide, carrying cross-border imports for forwarders and handing parcels outside its network to
Japan Post. TracX Logis names it as a delivery partner. Its site is ecohai.co.jp.

## Numbers

Its numbers have twelve digits with the same check digit as Japan Post's, Yamato's and Sagawa's,
so there is no rule.

## Why there is no adapter

The tracking page asks an open JSON endpoint without a session or CAPTCHA. No public number is
known to see a found reply.

## Links

The tracking page takes the number in its form, so no address opens one parcel.
