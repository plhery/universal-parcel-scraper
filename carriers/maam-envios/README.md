# MAAM Envíos

MAAM Envíos parcels use enabled universal providers. There is no dedicated adapter.

MAAM Envíos is a Madrid company that sells local, national and international courier services
under its own name, part of them carried by other couriers. Its own waybills are on its IRIS
tracker.

## Numbers

No public page shows a MAAM Envíos number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `maam.factapp.es`. No public
number is known to check its replies against.

## Links

`/IRIS/Seguimiento?s=<number>` opens one shipment, so the catalog links each number there. Each IRIS
tenant keeps its own shipments, so links are read only on the company's tenant.
