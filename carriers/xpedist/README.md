# Xpedist

Xpedist parcels use enabled universal providers. There is no dedicated adapter.

Xpedist is a city courier in Cluj-Napoca, Romania, for documents and parcels, with same-day and
two-hour delivery. Its site is xpedist.ro.

## Numbers

No public page shows a Xpedist number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows an AWB's steps and proof of delivery. With no public number to check its
replies against, there is no adapter.

## Links

The tracking page opens numbers from its `awb` parameter.
