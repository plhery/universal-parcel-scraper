# Optimus Courier

Optimus Courier parcels use enabled universal providers. There is no dedicated adapter.

Optimus Courier Logistics S.R.L. is a courier in Bistrița-Năsăud county in Romania that delivers parcels
under its own waybill (AWB) numbers. Its site is optimuscourier.ro.

## Numbers

No public page shows an Optimus Courier number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows an AWB's status, destination and scans. With no public number to check its
replies against, there is no adapter.

## Links

The tracking page opens numbers from its `awb_nr` parameter.
