# Fudu Logistics

Fudu Logistics parcels use enabled universal providers. There is no dedicated adapter.

Fudu Logistics is a Chinese forwarder. 17TRACK lists it under that name with the site
szfd56.com, and universal providers name it for parcels they track.

## Numbers

Fudu Logistics publishes no number format and no public page shows one of its numbers, so there
is no rule.

## Why there is no adapter

szfd56.com serves only a web server's default page, over plain HTTP, and has no tracker. The
canary probes 17TRACK, which tracks its parcels.
