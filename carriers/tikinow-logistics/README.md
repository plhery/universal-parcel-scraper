# TikiNOW Smart Logistics

TikiNOW Smart Logistics shipments use enabled universal providers. There is no dedicated adapter.

TikiNOW Smart Logistics (TNSL) is the delivery company of the Vietnamese marketplace Tiki. It is on Ho Chi Minh
City's register of postal enterprises.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker asks `POST https://api-tms.tiki.com.vn/express/tracking` with the number and an optional phone
number, which unlocks more detail. With no public number to check its replies against, there is no adapter.

## Links

`tnsl-tracking.tiki.com.vn/?id=<number>` opens one shipment.
