# Fixtures

The replies follow `getTrackingByNos` for one number: a JSON array with one item, its summary
status in Chinese, the countries in Chinese and the scans in English, newest first.
`in-transit.json` goes from the order data through import clearance to the local partner's
processing centre.
`not-found.json` has the shape of the tracker's answer for a number it does not know.

Numbers and clocks are invented.
