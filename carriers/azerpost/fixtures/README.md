# Fixtures

Replies of Azerpost's tracking lookup, `/api/get-package/en`.

- `departed.json`: the reply for the public sample in `numbers.json`, a registered letter posted in Baku for
  Australia, last scanned leaving Baku's outward office of exchange. It names no person.
- `not-found.json`: the reply for a synthetic code the tracker does not know, with the backend address it names
  replaced by a placeholder host.
