# Geis PL

Geis PL shipments use enabled universal providers. There is no dedicated adapter.

Geis PL, from Stryków, carries pallets, general cargo and parcels across Poland and abroad for the Geis group. The
Czech and Slovak Geis entry asks only those countries' tracker.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker is a page of geis.pl that reads the number from its address. With no public number to check the tracker's replies against, there is no adapter.

## Links

`geis.pl/pl/sledzenie-przesylki?packNumber=<number>` opens one consignment.
