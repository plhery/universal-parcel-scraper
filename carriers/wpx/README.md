# WPX Delivery Solutions

WPX Delivery Solutions parcels use enabled universal providers. There is no dedicated adapter.

WPX Delivery Solutions is a regional courier founded in Anchorage and based in Auburn,
Washington. It runs daily pickup and delivery for businesses by air, ocean and ground across
Alaska, Washington, Oregon, Idaho, western Montana, Nevada and Hawaii. Its site is wpx.com.

## Numbers

Its tracking numbers have no published layout, and no public page shows one, so there is no rule.

## Why there is no adapter

Its Quick Track link opens guest tracking on WPX's tenant of CXT Software's RapidShip portal, a
JavaScript app. No public number is known to see a found reply.

## Links

`01000.cxtsoftware.net/rapidship/#/track-order;trackingId=<number>` opens one parcel. Other
companies use the same host, so the rule is bound to WPX's `01000` subdomain.
