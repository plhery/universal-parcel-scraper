# Transilvania Post

Transilvania Post parcels use enabled universal providers. There is no dedicated adapter.

Transilvania Post is a courier in Cluj, Romania, that delivers letters and parcels under its own AWB
numbers. Its site is transilvaniapost.ro.

## Numbers

Its tracking form shows TRP before the number field. No public page shows a whole number, so there
is no rule.

## Why there is no adapter

Its tracking page shows an AWB's status by its number. With no public number to check its replies
against, there is no adapter.

## Links

The tracking page opens a number from its path, after `/awb/`.
