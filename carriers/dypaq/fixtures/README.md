# Fixtures

Replies of `POST https://www.dypaq.com/wp-json/dypaq_services/v1/tracking`. `delivered.json` is
the reply for the guía of DYPAQ's API documentation, delivered; the recipient's name, address and
postcode, who signed, the signature image and the coordinates in it and in the collection's map
link are replaced with invented values. `not-found.json` is the reply for an invented guía DYPAQ
holds nothing for.
