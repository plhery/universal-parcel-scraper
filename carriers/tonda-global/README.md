# Tonda Global

Tonda Global parcels use enabled universal providers. There is no dedicated adapter.

Tonda Global is a Qingdao supply-chain company running parcel and charter lines between China, Korea and
Mongolia. Its site is tarrive.com.

## Numbers

No public page shows a Tonda Global number, so there is no rule.

## Why there is no adapter

Its tracking page reads an open JSON API without a session or CAPTCHA, which answers an unknown number with
an empty list. No public number is known to see a found reply.

## Links

The tracking page opens numbers from its `q` parameter.
