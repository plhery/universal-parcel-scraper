# Pink Post

Pink Post parcels use enabled universal providers. There is no dedicated adapter.

Pink Post is a private postal operator in Romania that delivers letters and parcels across the
country. Its site is pinkpost.ro.

## Numbers

No public page shows a Pink Post number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows an AWB's steps, from registration to delivery, return or pickup at its
office. With no public number to check its replies against, there is no adapter.

## Links

The tracking page reads the number after `#/track/` in its address. Links do not read that part of
an address, so there is no link rule.
