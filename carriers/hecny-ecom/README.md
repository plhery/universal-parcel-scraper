# Hecny E-com

Hecny E-com parcels use enabled universal providers. There is no dedicated adapter.

Hecny E-com is the cross-border parcel service of Hecny Group CIS, the Russian arm of the Hecny
forwarder, carrying marketplace parcels from China and Turkey to Russia through customs to Russian
last-mile partners. Its site is hecny-cis.com. Its tracker, last on ecom.yolka.io, run by Hecny's IT
affiliate, answers no network.

## Numbers

No public page shows a Hecny E-com number, so there is no rule.

## Why there is no adapter

The tracker answers no network. When it answered, its page posted the number to an open JSON
service without a session or CAPTCHA, but no public number was known to see a found reply, and the
reply carried the recipient's address.

## Links

Each parcel had its own page, `/parcels/<number>`, on ecom.yolka.io and before that on
e-com.hecny.ru; the library reads both. Neither host answers, so the catalog links no page.
