# Liuchen

Liuchen parcels use enabled universal providers. There is no dedicated adapter.

Liuchen is a Shenzhen forwarder shipping parcels from China to Latin America. Its site is liuchenwl.com.

## Numbers

No public page shows a Liuchen number, so there is no rule.

## Why there is no adapter

Its tracker reads an open JSON lookup without a session or CAPTCHA, the system Jifan's and LinHan's trackers
use, which marks an unknown number as not found. No public number is known to see a found reply.

## Links

The tracker opens numbers from its `nos` parameter.
