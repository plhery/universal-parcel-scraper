# ATS Healthcare

ATS Healthcare parcels use enabled universal providers. There is no dedicated adapter.

ATS Healthcare (Andlauer Transportation Services) is a Canadian healthcare courier with branches
in every province, part of UPS Healthcare since UPS bought its parent in 2025. Its site is
atshealthcare.ca.

## Numbers

Its shipment numbers are eight or nine digits, lengths many carriers share, so there is no rule.

## Why there is no adapter

Its result page answers a plain address without a session and answered public numbers; an
adapter is possible and not yet written. It answers an unknown number with a placeholder
"Shipping label created" row and no detail, which an adapter would have to read as not found.

## Links

The result page opens a number from its `ship` parameter.
