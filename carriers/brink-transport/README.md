# Brink Transport

Brink Transport parcels use enabled universal providers. There is no dedicated adapter.

Brink Transport ApS is a Danish national haulier in Kolding, with terminals in Viborg and Brøndby,
for same-day, day-to-day and night distribution, parcels, and domestic and export freight. Its site
is brinktransport.dk.

## Numbers

The public example is thirteen digits. Thirteen bare digits fit many carriers' numbers, so there is
no rule.

## Why there is no adapter

Its tracker is an Opter track-and-trace site, as [Cargobus's](../cargobus/README.md) is. No found
reply has been seen.

## Links

`brinkdk.opter.cloud/tt?keyword=<number>` opens one parcel. Opter hosts many carriers, so only Brink
Transport's subdomain is read.
