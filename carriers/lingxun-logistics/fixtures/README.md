Replies of LingXun's Hualei tracker. `track.json` is the live answer for the public sample from
TrackShip's LingXun Logistics page, re-encoded as UTF-8 with the account and signatory fields
blanked and the account code in the invoice number and the shipper's reference zeroed.
`echo-unknown.json` and `page-unknown.html` are the live answers for `ZZQX00000000000`, a string in
no shape the tracker issues: the interface echoes it as a reference without an order, and the page
shows it the same way.
