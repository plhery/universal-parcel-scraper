# YTO Express Philippines

YTO Express Philippines parcels use enabled universal providers. There is no dedicated adapter.

YTO Express Philippines is the domestic Philippine courier YTO Express set up in 2021 with its own
branches. It is a separate network from [YTO Express](../yto/README.md) in China and runs its own
tracker at yto.com.ph.

## Numbers

The tracker's own input check accepts several layouts, one of them shared with YTO Express in
China, and no public page shows a YTO Express Philippines waybill, so there is no rule.

## Why there is no adapter

The tracker shows a slider check before each lookup, so YTO Express Philippines stays on
universal providers.

## Links

The tracker takes the number inside the page only, so no address opens one shipment and the
library reads no link.
