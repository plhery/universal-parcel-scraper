Replies of XendNow's tracking API for the example box on its tracking page, whose number and source are in
`numbers.json`: `history.json` from `track_parcel_history` and `detail.json` from `track_parcel_detail`.
The receiver's name, IC number and signature id, and the card's address and phone number, are blanked.
`not-found.json` is both routes' answer for an invented box.
