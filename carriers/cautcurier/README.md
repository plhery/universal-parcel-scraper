# CautCurier

CautCurier parcels use enabled universal providers. There is no dedicated adapter.

CautCurier is an urgent and same-day courier in Timișoara and Oradea, Romania. Its site is
cautcurier.ro.

## Numbers

No public page shows a CautCurier number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows an AWB's steps, including a failed delivery when nobody is home. With no
public number to check its replies against, there is no adapter.

## Links

The tracking page opens numbers from its `awb` parameter.
