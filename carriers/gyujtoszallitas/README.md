# Gyűjtőszállítás.hu

Gyűjtőszállítás.hu parcels use enabled universal providers. There is no dedicated adapter.

Gyűjtőszállítás.hu Futárszolgálat Kft. in Vecsés collects parcels and pallets from web shops
and delivers them across Hungary under its own label numbers. Parcels it sends through partner
couriers keep those couriers' numbers. Its site is gyujtoszallitas.hu.

## Numbers

No public page shows a Gyűjtőszállítás.hu label number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page asks `/get-package` with the label number (`bar_code`). With no public number
to check its replies against, there is no adapter.

## Links

The tracking page takes the number in its form, so no address opens one item.
