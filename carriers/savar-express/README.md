# SAVAR Express

SAVAR Express parcels use enabled universal providers. There is no dedicated adapter.

SAVAR Express (Simple Express S.A.C.) is a courier and e-commerce delivery company in Lima, Peru.
Its site is savarexpress.com.pe.

## Numbers

Its merchants tell buyers to track with a code made from the merchant's prefix and order number,
so it has no layout of its own and there is no rule.

## Why there is no adapter

Its tracker posts the code behind a Cloudflare Turnstile check.

## Links

The tracker opens no per-shipment page, so the catalog sends people to it.
