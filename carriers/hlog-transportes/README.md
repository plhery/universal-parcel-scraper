# HLOG

HLOG parcels use enabled universal providers. There is no dedicated adapter.

HLOG Transportes e Logística is a Brazilian carrier in Bahia. It carries part and full loads, air
cargo and marketplace parcels across the state of Bahia. Its site is hlogtransportes.com.br.

## Numbers

Its tracking codes are HL, ten digits and BR. Only its tracker's own example shows that shape, so
detection proposes HLOG for it at low confidence.

## Why there is no adapter

Its tracking page posts the code to `hlogtransportes.com.br/index/rastreamento_detalhes` and shows
the HTML reply in a dialog. No real code is public, so its found reply is unknown.

## Links

The tracking page takes the code in its form, so no address opens one parcel.
