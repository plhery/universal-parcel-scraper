# J&T Express Colombia

J&T Express Colombia parcels use enabled universal providers. There is no dedicated adapter.

J&T Express Colombia is J&T Express's Colombian network. Its site runs the same J&T tracking page
as [J&T Express UK](../j-and-t-uk/README.md), at jtexpress.co.

## Numbers

No public page shows a J&T Express Colombia waybill, so there is no rule.

## Why there is no adapter

Its tracking page shows the scans only after the last four digits of the sender's or the
recipient's phone number, so J&T Express Colombia stays on universal providers.

## Links

Tracking links carry the number in the `q` parameter of the tracking page. The page then asks
for the phone digits, so the catalog gives no tracking address.
