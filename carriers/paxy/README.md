# Paxy

Paxy shipments use enabled universal providers. There is no dedicated adapter.

Paxy collects Polish online shops' parcels with its own vans or at its hub in Wodzisław Śląski and delivers them to
customers across Europe through local couriers and pickup points.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker posts the number to `https://tracking.paxy.pl/tracking/check`. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
