# epaka.pl

epaka.pl shipments use enabled universal providers. There is no dedicated adapter.

epaka.pl, from Łuków, books shipments with partner couriers for businesses and private senders, runs its own drop-off
points and sells its own economy service. Its tracker finds a shipment by epaka's order number or the courier's
waybill.

## Numbers

No public page shows an epaka order number, so there is no rule.

## Why there is no adapter

The tracker is a POST form. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
