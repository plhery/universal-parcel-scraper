# Kart2Door

Kart2Door parcels use enabled universal providers. There is no dedicated adapter.

Kart2Door is SmartKargo's e-commerce delivery network in the United States, moving parcels on airline
cargo. Its site is kart2door.com.

## Numbers

No public page shows a Kart2Door number, so there is no rule.

## Why there is no adapter

Its tracker renders results as HTML without a session or CAPTCHA and answers an unknown number with a
not-found message. No public number is known to see a found reply.

## Links

The tracker opens numbers from its `axb` parameter.
