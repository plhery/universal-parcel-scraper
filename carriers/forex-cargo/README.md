# Forex Cargo

Forex Cargo shipments use enabled universal providers. There is no dedicated adapter.

Forex Cargo ships balikbayan boxes from the United States to the Philippines, with a warehouse in Valenzuela.
It is not [Forex Cargo Australia](../forex-cargo-au/README.md), which runs its own site and tracker.

## Numbers

No public page shows one of its box numbers, so there is no rule.

## Why there is no adapter

The box tracker at `apps.forexcargo.us/box_tracking2`, embedded in Forex eShip's page, loads its answer from a
script. With no public number to check its replies against, there is no adapter.

## Links

The tracker reads the box number only from its form, so no address opens one box.
