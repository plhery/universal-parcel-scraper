# Skif-Cargo

Skif-Cargo parcels use enabled universal providers. There is no dedicated adapter.

Skif-Cargo (Скиф-Карго), ООО «Компания Скиф-Карго», is a Russian road freight company for groupage,
deliveries to retail chains and express freight, with warehousing and 3PL services, through more
than 50 branches.

## Numbers

Its tracker finds a shipment by Skif-Cargo's application number or the customer's order number. No
public page shows a whole number or its layout, so there is no rule.

## Why there is no adapter

The tracker is a script app on the site, and the request it makes is not in its static code. With
no public number to check its replies against, there is no adapter.

## Links

The tracker takes the number only in its form, so no address opens one shipment.
