# Air Tahiti Nui Cargo

Air Tahiti Nui Cargo shipments use enabled universal providers. There is no dedicated adapter.

Air Tahiti Nui, French Polynesia's international airline, carries parcels, bulky items and unaccompanied baggage
between Papeete, mainland France and its other destinations.

## Numbers

It tracks a shipment by its air waybill, the airline prefix 244 and eight digits. No public page shows one, so
there is no rule.

## Why there is no adapter

The form on the freight page posts one or more air waybills. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
