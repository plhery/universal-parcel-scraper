# UBN Speed

UBN Speed shipments use enabled universal providers. There is no dedicated adapter.

UBN Speed Service France delivers parcels in mainland France and La Réunion from Paris. Speed24 is its local
brand on La Réunion.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The tracker is a server-rendered WordPress page. With no public number to check the tracker's replies against, there is no adapter.

## Links

`ubn-speed.fr/suivi-colis/?ubn_tracking=<number>` opens one parcel; the Réunion site's form links there too.
