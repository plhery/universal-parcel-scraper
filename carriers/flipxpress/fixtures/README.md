# Fixtures

Replies of `GET portal.flipxp.com/apis/manifest_status_multiple`, the lookup Flip Xpress's tracking page
asks, with the addresses and the name of whoever took the parcel replaced by placeholders.

- `delivered.json`: the reply for the first public sample in [`numbers.json`](../numbers.json), a delivered
  shipment.
- `not-found.json`: the reply, with HTTP 200, for an invented number.
