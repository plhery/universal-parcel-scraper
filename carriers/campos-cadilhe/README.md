# Campos&Cadilhe

Campos&Cadilhe parcels use enabled universal providers. There is no dedicated adapter.

Campos&Cadilhe (Campos & Cadilhe Lda) is an express courier in Matosinhos, near Porto, with
twice-daily pickup and delivery across Portugal's main metropolitan areas. Its site is c-c.pt.

## Numbers

Parcels are tracked by their waybill number, which has no published layout, and no public page shows
one, so there is no rule.

## Why there is no adapter

Its tracker, OTM (Online Transport Manager), opens `/track/<number>` from its form's script. No
found page has been seen.

## Links

`otm.camposcadilhe.pt/track/<number>` opens one parcel.
