# Fixtures

The result block of the page GEL's tracker renders for a number alone, cut from the rest of the
WordPress page. Scripts, styles and icons' vector art are left out; among the scripts is a link
that sets the parcel's safe-drop permission.

- `delivered.html`: the page for the review's parcel in `numbers.json`, delivered, with its
  progress rail.
- `not-found.html`: the notice for a synthetic number the tracker does not know.
