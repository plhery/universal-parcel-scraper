Synthetic pages in the shape of ParcelABC's tracking page: `delivered.html` is a delivered order of
two parcels with the same rows, `in-transit.html` an order of one parcel in transit with a note on
top, each drawn twice for wide and narrow screens as the page does. `not-found.html` is the home
page with the notice an unknown code's redirect leaves. Order codes, clocks, places, comments, the
recipient, phone number, e-mail address, postcode, header and footer are invented.
