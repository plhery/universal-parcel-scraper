# Fixtures

The result block of the page ODM's tracker renders for one guide, cut from the rest of the
WordPress page. The page never closes its table, which the cut keeps, with the paragraphs after it.

- `delivered.html`: the page for the public sample in `numbers.json`, from documentation in
  Chihuahua to delivery, with the courier's name, the documenting employee's user and the
  receipt image's address replaced by synthetic ones.
- `not-found.html`: the notice for a synthetic guide the tracker does not know.
