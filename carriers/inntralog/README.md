# Inntralog

Inntralog parcels use enabled universal providers. There is no dedicated adapter.

Inntralog is Rhenus Home Delivery's two-man delivery company for furniture and large appliances in Germany. It
runs its own tracker and numbers; Rhenus Germany is a separate entry. Its site is inntralog.de.

## Numbers

Its numbers are eight digits, the order number on Rhenus's delivery portal too. Eight digits are shared by other
carriers and no public page shows one, so there is no rule.

## Why there is no adapter

Its tracker needs the recipient's postcode with the number.

## Links

The tracker's result address carries the postcode, so no link names it.
