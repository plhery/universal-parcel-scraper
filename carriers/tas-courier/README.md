# TAS Courier

TAS Courier parcels use enabled universal providers. There is no dedicated adapter.

TAS Courier E.E. is an Athens courier founded in 2002. It delivers in Attica with its own network
and hands the rest of Greece to partner couriers, whose voucher its tracker shows. Its site is
tascourier.gr.

## Numbers

No public page shows a TAS Courier voucher, so its layout is unknown and no rule names it.

## Why there is no adapter

The tracker's results endpoint answers without its page's CAPTCHA, but no public voucher has
been found to check it with. Its rows also name the recipient and the courier, which an adapter
must leave out.

## Links

The tracker opens a voucher from its `v` parameter.
