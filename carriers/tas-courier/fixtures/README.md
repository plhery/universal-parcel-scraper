# Fixtures

Replies of `result.php?add_event=1&r18p01=<voucher>&having=1`, the list TAS Courier's Pegasus Hermes
voucher search loads in the session its page opens.

- `delivered.html`: the reply for the first public sample in [`numbers.json`](../numbers.json), with the
  recipient's first name and the person who delivered replaced by placeholders.
- `assigned.html`: the reply for the second public sample, whole: the tracker masks its recipient.
- `not-found.html`: the reply for an invented voucher, the column headings alone.
