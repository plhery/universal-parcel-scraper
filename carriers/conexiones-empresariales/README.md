# Conexiones Empresariales

Select Conexiones Empresariales and enter the numeric guide for the Colombian messenger. The public lookup opens a guide by number, and the adapter verifies the number in the result. [Official tracker](https://app.conexionesempresariales.com/rastreo/)

The page shows one outcome and its date. The adapter keeps day precision and reports the destination city with a confirmed delivery. It omits the recipient name, contact details and full address.

```sh
CONEXIONES_EMPRESARIALES_TRACKING_NUMBER=… npm run test:carriers:live -- carriers/conexiones-empresariales
```
