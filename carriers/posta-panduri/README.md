# Poșta Panduri

Poșta Panduri parcels use enabled universal providers. There is no dedicated adapter.

Poșta Panduri, run by C Solution S.R.L. in Bucharest, delivers parcels in Romania through its
Pachetomat lockers and couriers, and for online shops through its LivrariOnline platform. Its site is
postapanduri.ro.

## Numbers

No public page shows a Poșta Panduri number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows an AWB's status. With no public number to check its replies against, there
is no adapter.

## Links

The tracking page opens numbers from its `awb` parameter.
