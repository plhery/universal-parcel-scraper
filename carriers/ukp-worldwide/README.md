# UKP Worldwide

UKP Worldwide parcels use enabled universal providers. There is no dedicated adapter.

UKP Worldwide (UK Postings Limited, formerly Mail Right International) is a customs agent and
consolidator near Aylesbury, sending e-commerce mail and parcels from the United Kingdom to the
United States and other countries, where a postal partner delivers them. Its site is
ukpworldwide.com.

## Numbers

An archived lookup on its own tracker shows WHISU and nine digits, which looks like one client's
series. It is one sample, so the rule is low and covers that prefix only.

## Why there is no adapter

The tracking page is an open server-rendered page that answers the public number with its
history and an unknown number with a clear not-found message, without a session or CAPTCHA. An
adapter can follow.

## Links

The tracking page opens the number from its `x` parameter.
