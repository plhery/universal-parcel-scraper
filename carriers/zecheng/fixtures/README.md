# Fixtures

The replies follow `getTrackingByNos` for one number: a JSON array with one item, its summary
status in Chinese, the countries in Chinese and the scans in English, newest first.
`in-transit.json` is a known number's reply, the array encoded once more as a JSON string, with
the order data as its only scan.
`not-found.json` has the shape of the tracker's answer for a number it does not know: the array
itself.

Numbers and clocks are invented.
