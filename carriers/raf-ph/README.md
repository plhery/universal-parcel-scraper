# RAF International Forwarding

RAF International Forwarding shipments use enabled universal providers. There is no dedicated adapter.

RAF International Forwarding, on NAIA Avenue in Manila, is a freight forwarder and customs broker with an express
and e-commerce service, RAF Express.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

Its guest tracker is a FrontierForce GETOnline page, like [Cristão Shipping](../cristao-shipping/README.md)'s.
With no public number to check its replies against, there is no adapter.

## Links

`tracking.frontierforce.com/go/plm-tracking?cn=<number>&stid=raf` opens one shipment under RAF's brand.
