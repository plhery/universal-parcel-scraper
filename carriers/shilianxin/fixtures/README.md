Replies of Shilianxin's Hualei tracker. `delivered.json` is the live answer for the public sample
from a tracking directory's Shilianxin page, re-encoded as UTF-8 with the consignee, shipper,
signature, fee, account and weight fields blanked; the delivering post office's ZIP code reads
`00000`. `no-track.json` and `page-unknown.html` are the live answers for an invented number.
