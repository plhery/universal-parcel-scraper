# VT Freight Express

VT Freight Express parcels use enabled universal providers. There is no dedicated adapter.

VT Freight Express, formerly VicTas Freight Express, carries parcels, skids and pallets between Melbourne,
Tasmania and the eastern states. Freightways owns it. Its site is vtfe.com.au.

## Numbers

Its consignment numbers open with a prefix set per sender, such as four letters and seven digits or three letters
and eleven digits, as archived lookups on its own tracker show. The prefixes name senders, not the carrier, so
there is no rule.

## Why there is no adapter

Its tracker is a TransVirtual page, as Hunter Express's is, answering an open GET without a session or CAPTCHA.
It no longer finds the archived numbers, and no current public number is known.

## Links

The tracker takes the number in its path.
