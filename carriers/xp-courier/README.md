# XP Courier

XP Courier parcels use enabled universal providers. There is no dedicated adapter.

XP Courier is a courier in Metamorfosi, Athens, Greece, with its own sorting hub. Its network covers
most of Attica, and ACS delivers for it in the rest of Greece. Its site is xpcourier.gr.

## Numbers

No public page shows an XP Courier number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page shows a shipment's events: picked up, at the XP sorting facility, out for
delivery, delivered, failed, refused, held or returned. With no public number to check its replies
against, there is no adapter.

## Links

The tracking page opens numbers from its `identifier` parameter.
