# MZZ-Briefdienst

MZZ-Briefdienst parcels use enabled universal providers. There is no dedicated adapter.

MZZ-Briefdienst is the private postal service of Mediengruppe Mitteldeutschland in Halle (Saale).
It carries letters, registered mail, parcels and courier shipments in Saxony-Anhalt and eastern
Lower Saxony. Its site is mzz-briefdienst.de. Its Magdeburg sister company, biber post, shares
its sent24 portal, so that name leads here too.

## Numbers

No public page shows an MZZ-Briefdienst number, so there is no rule.

## Why there is no adapter

Its "Wo ist meine Sendung?" page posts the number from a form to the parcel portal at
portal.sent24.de, which tracks parcels and registered mail. No public number is known to see a
found reply.

## Links

The portal takes the number only through its form, so no address opens one parcel.
