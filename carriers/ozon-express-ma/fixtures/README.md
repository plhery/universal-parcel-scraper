# Fixtures

Replies of `POST api.ozonexpress.ma/customers/tracking-new`, the lookup Ozon Express's tracking box makes.

- `delivered.html`: the whole reply for the public sample in [`numbers.json`](../numbers.json), a delivered parcel,
  asked in the case its review wrote it. The tracker echoes the number as it was sent.
- `not-found.html`: the whole reply for an invented number.
