# OVERNITE

OVERNITE parcels use enabled universal providers. There is no dedicated adapter yet.

OVERNITE is a German courier for hunting and sport weapons, ammunition, valuables and dry-ice
shipments, with identity and age checks at delivery. It is not
[Best Overnite Express](../best-overnite-express/README.md).

## Numbers

No public page shows an OVERNITE shipment number, so no rule names it.

## Tracker

The tracker asks a JSON interface without a session or CAPTCHA, but its form needs the delivery
postcode, and its replies carry the recipient's town and the signer's name.
