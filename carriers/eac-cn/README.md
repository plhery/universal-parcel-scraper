# EAC

EAC parcels use enabled universal providers. There is no dedicated adapter.

EAC (Fuhuang Meiyun) is a Shenzhen forwarder shipping marketplace stock and parcels from China to North
America and Europe. Its site is szeac.com.

## Numbers

No public page shows an EAC number, so there is no rule.

## Why there is no adapter

Its tracker posts numbers to an open JSON endpoint without a session or CAPTCHA, which answers an unknown
number with an empty list. No public number is known to see a found reply.

## Links

Its tracker has no address for a single number, so no link names it.
