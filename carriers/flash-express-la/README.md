# Flash Express Laos

Flash Express Laos parcels use enabled universal providers. There is no dedicated adapter.

Flash Express Laos (Flash Express Lao Sole Co., Ltd.) is Flash Express's Lao network. Its site runs
the same tracking page as [Flash Express](../flash-express/README.md) in Thailand.

## Numbers

No public page shows a Flash Express Laos number, so there is no rule.

## Why there is no adapter

Its tracking page posts the numbers to the same tracking endpoint and reply shape as the Thai
site, on flashexpress.la, without a login. With no public number to check its replies against,
there is no adapter yet.

## Links

`flashexpress.la/fle/tracking?se={number}` opens the tracker with the number filled in, also
under a language prefix.
