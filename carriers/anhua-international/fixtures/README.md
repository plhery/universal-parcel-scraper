Replies of Anhua International's Hualei track interface, re-encoded from GBK as UTF-8.
`delivered.json` is the live answer for the first public sample from TrackShip's Anhua International
page; its recipient, sender and signature fields came blank, and the signatory Australia Post's
delivery row names is replaced by a synthetic one. `no-track.json` is the live answer for a made-up
number the tracker does not know. The page's answer for an unknown number is the platform's shared
one in [`../../gzyl/fixtures/page-unknown.html`](../../gzyl/fixtures/page-unknown.html).
