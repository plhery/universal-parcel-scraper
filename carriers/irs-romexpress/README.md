# International Romexpress Service

International Romexpress Service parcels use enabled universal providers. There is no dedicated adapter.

International Romexpress Service (IRS) is a courier, forwarder and customs broker at Bucharest's
Otopeni airport that issues its own waybills. Its site is irs.ro.

## Numbers

No public page shows an International Romexpress Service number or its layout, so there is no rule.

## Why there is no adapter

Its home page tracks export waybills in a window that posts the number. With no public number to
check its replies against, there is no adapter.

## Links

The tracker takes numbers only through its window, so no address opens one item.
