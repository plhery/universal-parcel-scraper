# EFS Asia

EFS Asia parcels use enabled universal providers. There is no dedicated adapter.

EFS is an Incheon cross-border e-commerce shipper sending Korean shops' orders abroad and handing them to a
delivery carrier in the destination country. Its site is efs.asia.

## Numbers

No public page shows an EFS number, so there is no rule.

## Why there is no adapter

Its tracker renders results as HTML without a session or CAPTCHA and answers an unknown number with a
not-found message; its times carry no zone. No public number is known to see a found reply.

## Links

The tracker opens numbers from its `search_no` parameter.
