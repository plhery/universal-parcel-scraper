# TransNatur

TransNatur parcels use enabled universal providers. There is no dedicated adapter.

TransNatur is a Spanish road transport and parcel company based in Paterna, Valencia. Its site is
transnatur.com.

## Numbers

No public page shows a TransNatur number, so there is no rule.

## Why there is no adapter

Its tracker is a Blazor Server page that sends results over a websocket, with no JSON endpoint, and shows
an empty grid for an unknown number rather than saying it is not found.

## Links

The tracker takes the number in its path.
