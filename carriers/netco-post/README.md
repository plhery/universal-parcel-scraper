# NETCO POST

NETCO POST shipments use enabled universal providers. There is no dedicated adapter.

NETCO POST is an express courier from Hanoi serving all of Vietnam. It is on Vietnam's list of licensed postal enterprises.

## Numbers

No public page shows one of its numbers; the form's placeholder is an example, so there is no rule.

## Why there is no adapter

With no public number to check the tracker's replies against, there is no adapter.

## Links

`netco.com.vn/vi/tracking?code=<number>` opens one waybill. The page also reads `type`, which defaults to a
waybill.
