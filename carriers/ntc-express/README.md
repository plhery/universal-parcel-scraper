# NTC Express

NTC Express parcels use enabled universal providers. There is no dedicated adapter.

NTC Express is the courier service of NTC Logistics, NTC LOGISTIC d.o.o. of Nikšić, a
Montenegrin logistics company with warehousing, fulfilment, distribution and international road
transport. It delivers door to door across Montenegro.

## Numbers

Its tracker finds a shipment by the code the recipient gets in a Viber message or from the
sender. No public page shows a whole code or its layout, so there is no rule.

## Why there is no adapter

The tracking page shows the shipment's status and, while the courier is on the round, the
courier's position on a map. With no public code to check its replies against, there is no
adapter.

## Links

`https://ntclog.me/?page=shipment-tracking&lang=me&shipment_code={trackingNumber}` opens the
tracker on the code, as its form sends it. A pasted `ntclog.me` link with a `shipment_code`
names NTC Express.
