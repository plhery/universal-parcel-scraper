# Trans-Ontario Express

Trans-Ontario Express parcels use enabled universal providers. There is no dedicated adapter.

Trans-Ontario Express (Trans Ontario) is a Toronto courier and freight carrier, founded in 1979,
serving the Greater Toronto Area, Canada and the United States. Its site is trans-ontario.com.

## Numbers

Its waybills are a customer's three-letter account code and the order number. No public one
has been found, so there is no rule.

## Why there is no adapter

Its tracker at trace.transontario.com answers a posted form without a session, but no public
waybill has been found to check a reply with.

## Links

The tracker takes the waybill only in a posted form and opens no per-waybill page, so the
catalog sends people to it.
