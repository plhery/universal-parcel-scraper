# NG.network

NG.network shipments use enabled universal providers. There is no dedicated adapter.

NG.network, from Niederaula in Hesse, is a cooperation of German general-cargo hauliers, Honold and Rüdinger among
them. A partner haulier's consignment travels under the network's numbers and is tracked on this page, so members are not
separate carriers.

## Numbers

Its help pages say its numbers begin with 81; a colli number is `00` and the shipper's SSCC. Neither has a public
sample, so there is no rule.

## Why there is no adapter

The tracker is the same WebAccess application as CargoLine's and Schäflein's. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker keeps the number in the path, as Schäflein's does, sometimes followed by the postcode, which the link
rule leaves out.
