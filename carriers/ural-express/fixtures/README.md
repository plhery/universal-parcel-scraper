# Ural Express fixtures

Replies of the tracking page's `trackByWaybillNums` call, whole. They hold no recipient details.

- `delivered.json`: the reply for the first public sample in [`numbers.json`](../numbers.json), a parcel
  from China by land to Moscow, cleared there and handed over at a pickup point in Russia.
- `listed.json`: the reply for the last public sample, listed with its marketplace order number and no rows.
- `not-found.json`: the reply for an invented number, an empty list.
