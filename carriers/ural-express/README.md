# Ural Express

Ural Express parcels use enabled universal providers. There is no dedicated adapter.

Ural Express (URAL) is a Chinese cross-border logistics company shipping marketplace parcels and freight to
Russia and Israel. Its site is uralsvip.com, and its tracker runs on a TMS hosted by iLine Express.

## Numbers

No public page shows a Ural Express number, so there is no rule.

## Why there is no adapter

Its tracker reads an open JSON API without a session or CAPTCHA and answers an unknown number with an
empty list. No public number is known to see a found reply.

## Links

Its tracker has no address for a single number, so no link names it.
