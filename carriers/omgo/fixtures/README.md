# Fixtures

`in-transit.json` is synthetic ParcelsApp history for an OMGO shipment. Names,
clocks and event text are invented; the provider envelope and carrier labels
retain the response shape.

`tracking-page.html` contains a synthetic page configuration, and `tracking.json`
uses the official direct response shape with a synthetic number, clocks, locations
and invoice reference. `unknown.json` reproduces the generic, unbound error shape.
