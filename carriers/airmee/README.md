# Airmee

Airmee parcels use enabled universal providers. There is no dedicated adapter.

Airmee (Airmiz AB) is a Swedish and Danish same-day and evening e-commerce courier, with pickup
points and parcel lockers. Its site is airmee.com.

## Numbers

No public shipment id has been found, so there is no rule.

## Why there is no adapter

Its tracker at tracking.airmee.com reads an open JSON lookup, but it asks for a date window of
at most fifteen days with the shipment id, and no public id has been found to check it with.
The links in Airmee's text messages ask for the recipient's phone.

## Links

The search page opens no per-shipment address, so the catalog sends people to it.
