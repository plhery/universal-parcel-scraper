# Samoa Post

Samoa Post parcels use enabled universal providers. There is no dedicated adapter.

Samoa Post is Samoa's postal operator. Its site is samoapost.ws.

## Numbers

Its items carry UPU S10 numbers ending `WS`, which postal detection reads. No public page shows one,
so there is no rule of its own.

## Why there is no adapter

Its home page embeds the UPU's hosted tracker, which asks for an image CAPTCHA.

## Links

Its tracker has no address for a single number, so no link names it.
