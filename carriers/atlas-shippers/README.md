# Atlas Shippers

Atlas Shippers shipments use enabled universal providers. There is no dedicated adapter.

Atlas Shippers International ships balikbayan boxes by sea from branches across the United States, Carson in
California among them, to the Philippines.

## Numbers

The tracker takes an invoice number. No public page shows one, so there is no rule.

## Why there is no adapter

The tracker posts the invoice number with a reCAPTCHA v3 answer. With no public number to check its replies
against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
