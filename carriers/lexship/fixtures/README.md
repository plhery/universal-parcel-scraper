# Fixtures

Replies of `POST live1.lexship.com/api/tracking/new`, the lookup LEXSHIP's tracking page posts the number to.

- `delivered.json`: the reply for the public sample in [`numbers.json`](../numbers.json), an export from India
  delivered in Belarus, with the consignee's name replaced.
- `not-found.json`: the reply, with HTTP 200, for an invented number.
