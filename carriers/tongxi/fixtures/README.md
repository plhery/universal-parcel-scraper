Replies of TongXi's Hualei track interface, re-encoded from GBK as UTF-8. `delivered.json` is the
live answer for the public sample from TrackShip's TongXi page, whole: its recipient fields came
blank. `no-track.json` is the live answer for a made-up number the tracker does not know. The
page's answer for an unknown number is the platform's shared one in
[`../../gzyl/fixtures/page-unknown.html`](../../gzyl/fixtures/page-unknown.html).
