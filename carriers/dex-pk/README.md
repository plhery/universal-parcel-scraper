# DEX Pakistan

DEX Pakistan parcels use enabled universal providers. There is no dedicated adapter.

DEX (Daraz Express) is the Daraz marketplace's delivery network in Pakistan. Its site is dex.com.pk.

## Numbers

Its numbers are `PK-DEX` and nine digits, which `dex-pk-1` suggests at high confidence: buyers post them on
complaint sites, an archived lookup on its own tracker shows one, and its tracker finds the recent ones.

## Why there is no adapter

Its tracking page reads an open JSON API without a session or CAPTCHA, on the same platform as LEX
Malaysia's. The API finds a number only with its hyphen.

## Links

The tracking page opens numbers from its `references` parameter, but only with the hyphen, so no portal link
is published.
