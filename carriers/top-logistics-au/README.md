# Top Logistics Australia

Top Logistics Australia parcels use enabled universal providers. There is no dedicated adapter.

Top Logistics Australia is a Sydney forwarder clearing low-value e-commerce imports and handing parcels to
Australian delivery carriers. Its site is toplogistics.com.au.

## Numbers

No public page shows a Top Logistics Australia number, so there is no rule.

## Why there is no adapter

Its site's search opens a tracking frame whose lookup answers an unknown number with an empty HTTP 500,
which cannot be told apart from a fault. No public number is known to see a found reply.

## Links

The site's search opens numbers from its `s` parameter.
