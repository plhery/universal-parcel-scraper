Replies of Jieyi Tongda's Hualei tracker. `delivered.json` is the live answer for the public sample
from a tracking directory's JYTD page, re-encoded as UTF-8 with the account and signatory fields
blanked and the shipper's reference zeroed. `page-delivered.html` is the tracking page's live
answer for the same sample, with the recipient's name replaced by a placeholder and the shipper's
reference zeroed. `no-track.json` and `page-unknown.html` are the live answers for a number in a
shape the tracker cannot hold.
