# Paquetería Vencedor

Grupo Vencedor delivers parcels and freight in Mexico. The adapter opens a fresh guest
session on its paquetería page, submits the guide through its public form and reads the
timeline after the redirect. The result must repeat the entire guide and agree on the
current status. The missing-guide notice asks the reader to try later, so it is indeterminate.

Events keep the office name and local wall clock shown by the carrier. The portal does not
state a time zone for each scan. The tracking link opens the search form because the results
depend on the form submission.

Run the live test with `PAQUETERIA_VENCEDOR_NUMBER` supplied in the environment and
`npm run test:carriers:live -- carriers/paqueteria-vencedor`.
