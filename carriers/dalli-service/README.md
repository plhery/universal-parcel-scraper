# Dalli

Dalli parcels use enabled universal providers. There is no dedicated adapter.

Dalli (ДАЛЛИ), ООО «ДАЛЛИ-СЕРВИС» of Moscow, is a Russian courier for online shops: last-mile
delivery in Moscow and St Petersburg and next-day delivery to more than 60 towns.

## Numbers

Its tracker finds an order by Dalli's shipment number or the shop's order number. No public page
shows a whole number or its layout, so there is no rule.

## Why there is no adapter

The tracker asks for the recipient's phone as well as the number. With no public number to check
its replies against, there is no adapter.

## Links

The tracker's form sends the number and the phone together, so no address opens a shipment with
the number alone and the catalog sends people to the tracking page.
