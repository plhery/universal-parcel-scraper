# AmeriShip

AmeriShip parcels use enabled universal providers. There is no dedicated adapter yet.

AmeriShip, formerly STAT Overnight Delivery, is a regional overnight courier based in Dallas,
serving Texas and nearby states.

## Numbers

No public page shows an AmeriShip or Stat Overnight shipment number, so no rule names it.

## Tracker

The tracking page renders a shipment on the server from a plain GET without a CAPTCHA.

## Links

The tracking page reads the number from its `n` parameter; Stat Overnight's former results page
read it from `tracking`.
