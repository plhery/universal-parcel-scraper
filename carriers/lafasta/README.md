# Lafasta

Lafasta parcels use enabled universal providers. There is no dedicated adapter.

Lafasta is an e-commerce courier in Riyadh, with in-city delivery, storage, fulfilment and packaging
for online shops. Its site is lafasta.sa.com.

## Numbers

Its numbers have no published layout, and no public page shows one, so there is no rule.

## Why there is no adapter

Its tracker's form script opens `/Track/<number>` on c.lafasta.sa.com. No found page has been seen.

## Links

`c.lafasta.sa.com/Track/<number>` opens one parcel.
