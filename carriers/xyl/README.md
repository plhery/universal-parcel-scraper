# XYL

XYL parcels use enabled universal providers. There is no dedicated adapter.

XYL (兴远国际, Xingyuan International Logistics) runs lines from China to Russia, Kazakhstan, Belarus
and Central Asia, handing parcels to local carriers and marketplaces. Its site is 816kf.com. 兴源
on xyexp.com is a different company, so the bare name Xingyuan is not an alias.

## Numbers

Its site gives no number layout and no public page shows an XYL number, so there is no rule.

## Why there is no adapter

Its tracker is a tenant of the Kingtrans platform, which answers an open XML lookup without a
session or CAPTCHA, but it blocks an address for a while after two quick requests. No public number
is known to see a found reply.

## Links

The Kingtrans tracking page opens the number from its `bills` parameter.
