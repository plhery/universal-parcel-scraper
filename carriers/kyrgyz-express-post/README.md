# Kyrgyz Express Post

Kyrgyz Express Post parcels use enabled universal providers. There is no dedicated adapter.

Kyrgyz Express Post is the second designated postal operator of Kyrgyzstan, beside
[Kyrgyz Post](../kyrgyz-post/README.md). It runs its own site and tracker at kep.kg.

## Numbers

Its items carry S10 numbers ending in KG, the same layout as Kyrgyz Post's, and no public
document gives it a series of its own, so the Kyrgyz Post rule keeps the shape and no rule names
Kyrgyz Express Post.

## Why there is no adapter

The tracker posts up to ten numbers in a form without a login. With no public number to check
its replies against, there is no adapter.

## Links

The tracker takes numbers in a posted form, so no address opens one shipment and the library
reads no link.
