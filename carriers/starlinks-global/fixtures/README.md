# Fixtures

Tracking pages of Starlinks Global's tracker, `starlinks.app/track/{number}`.

- `delivered.html`: a parcel from a British hub, through customs, handed to an American courier
  and delivered, with the courier's number and tracking link.
- `not-found.html`: the page for a number the tracker does not know.

Numbers, places, the shop, the courier's service and the token are invented.
