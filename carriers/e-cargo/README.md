# e-Cargo

e-Cargo parcels use enabled universal providers. There is no dedicated adapter yet.

e-Cargo, of the Cargo Amerford group, imports e-commerce parcels into Israel and delivers them.

## Numbers

Its contact page says numbers usually start with `EC`; no public page shows one, so no rule
names it.

## Tracker

The tracker asks an open JSON interface without a login, but can ask for an image CAPTCHA
after repeated searches.

## Links

The tracker reads the number from its `searchKey` parameter.
