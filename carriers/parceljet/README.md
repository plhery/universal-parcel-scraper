# Parceljet

Parceljet parcels use enabled universal providers. There is no dedicated adapter.

Parceljet (派速捷) is a Guangzhou cross-border logistics company running parcel lines and overseas
warehouses from China, with a Japanese arm. Its site is parceljet.com.

## Numbers

No public page shows a Parceljet number, so there is no rule.

## Why there is no adapter

The tracking page posts the number to an open JSON service without a session or CAPTCHA, which
answers an unknown number with "订单不存在". No public number is known to see a found reply.

## Links

The tracking page keeps the number out of its address, so no address opens one parcel.
