# QWQER

QWQER parcels use enabled universal providers. There is no dedicated adapter.

QWQER is a last-mile and city courier founded in Latvia whose couriers work through its own
platform. This entry is its EU network, run by QWQER EU SIA in Riga, which delivers in Latvia,
Lithuania and Poland. QWQER's Indian service is a separate company and is not covered. Its site is
qwqer.eu.

## Numbers

A courier request gives each delivery an ID with no published layout, and no public page shows
one, so there is no rule.

## Why there is no adapter

Its tracking page is a Laravel Livewire component that sends the typed code through Livewire's own
update requests. No public number is known to see a found reply.

## Links

The tracking page takes the code only through its form, so no address opens one parcel.
