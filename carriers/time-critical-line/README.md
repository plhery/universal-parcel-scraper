# Time Critical Line

Time Critical Line parcels use enabled universal providers. There is no dedicated adapter.

Time Critical Line is a forwarder and courier at Bucharest's Otopeni airport for urgent shipments,
including on-board couriers and air freight. Its customers get an order number with their booking.

## Numbers

No public page shows a Time Critical Line number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page takes an order number through a form with a token. With no public number to check
its replies against, there is no adapter.

## Links

The form posts the number with a token, so no address opens one item.
