# LetterTrack

LetterTrack mail uses enabled universal providers. There is no dedicated adapter.

LetterTrack prints a USPS Intelligent Mail barcode on First-Class letters, flats and padded
envelopes, which USPS then scans on their way. USPS's own tracker does not show these scans, so
LetterTrack's page is where they are read. Its site is letter-track.com.

## Numbers

Numbers are USPS Intelligent Mail codes carrying LetterTrack's mailer id. The one public page that
shows one also shows the recipient, so it is not cited and there is no rule.

## Why there is no adapter

The tracking page shows the sender's and recipient's names and addresses with the scans.

## Links

The tracking form is not linked to one item, so no address opens one.
