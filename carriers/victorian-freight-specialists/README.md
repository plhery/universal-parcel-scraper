# Victorian Freight Specialists

Victorian Freight Specialists parcels use enabled universal providers. There is no dedicated adapter.

Victorian Freight Specialists is a Dandenong South general freight carrier serving metropolitan and regional
Victoria. Its site is vfs.com.au.

## Numbers

No public page shows a Victorian Freight Specialists number, so there is no rule.

## Why there is no adapter

Its tracker, an Imagesoft WebConsignment page, reads the number without a session or CAPTCHA and says when no
tracking information is available. No public number is known to see a found reply.

## Links

The search page opens numbers from its `connum` parameter.
