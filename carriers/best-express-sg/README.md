# BEST Express Singapore

BEST Express Singapore parcels use enabled universal providers. There is no dedicated adapter.

BEST Express Singapore (BEST Logistics Technology (Singapore) Pte. Ltd.) is the Singapore parcel
network of BEST Inc. Its tracker at best-inc.sg runs on the same platform as
[BEST Express Malaysia](../best-express-my/README.md)'s.

## Numbers

No public page shows a BEST Express Singapore waybill, so there is no rule.

## Why there is no adapter

The tracker shows BEST's own captcha before it answers, as on the Malaysian and Vietnamese
sites, so BEST Express Singapore stays on universal providers.

## Links

`best-inc.sg/track?bills={number}` opens the tracker with the number filled in; the tracker
script also reads `waybill`.
