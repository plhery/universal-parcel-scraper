# Fixtures

Replies of the `get_consignment` action at `www.cope.com.au/wp-admin/admin-ajax.php`, as they came:
eSmart's tracking page for the number.

Each public sample's page in [`numbers.json`](../numbers.json) is named after it: the first created in
Broadmeadows, Victoria, and delivered in Western Australia; the second picked up and moved at the same
minute, then delivered in New South Wales. `not-found.html` is the page for an invented number, with
every field empty and no row.

Rows name a suburb and state at most; the pages name no sender, receiver or address.
