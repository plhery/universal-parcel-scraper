# COPE Sensitive Freight

COPE Sensitive Freight parcels use enabled universal providers. There is no dedicated adapter.

COPE Sensitive Freight (Janala Pty Limited) is an Australian road carrier for fragile and
high-value goods with a national depot network. Its site is cope.com.au.

## Numbers

Archived consignment-note file names show the sending customer's three-letter code and seven
digits, a common layout, and no public note has been seen tracked, so there is no rule.

## Why there is no adapter

Its homepage tracker posts the number to the site's open AJAX action and gets an HTML fragment
back, but no public note has been found to check a found reply with; an unknown one gets an
empty template.

## Links

The tracker reads numbers from a form and opens no per-consignment page, so the catalog sends
people to the homepage.
