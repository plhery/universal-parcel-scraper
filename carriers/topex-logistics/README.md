# Topex Logistics

Topex Logistics parcels use enabled universal providers. There is no dedicated adapter.

Topex Logistics (迅派物流, Shenzhen Xunpai Logistics Technology) ships from China to Brazil, where it
runs a warehouse and pickup point for marketplaces. Its site is topex.group. TOPEX in the United Arab
Emirates is a different company, so the bare name is not an alias.

## Numbers

Its site gives no number layout and no public page shows a Topex number, so there is no rule.

## Why there is no adapter

Its tracker on tms.topex.group answers plain HTTP only and requires a slider CAPTCHA before it
looks a number up.

## Links

The tracker is HTTP only, so the catalog opens the site, which links it.
