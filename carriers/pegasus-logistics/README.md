# Pegasus Logistics Group

Pegasus Logistics Group shipments use enabled universal providers. There is no dedicated adapter.

Pegasus Logistics Group carries expedited freight, forwards shipments and delivers white-glove and final-mile orders.

## Numbers

No public page shows one of its numbers, so there is no rule.

## Why there is no adapter

The site's "Track My Shipment" button opens a guest page on its partner portal. With no public number to check the tracker's replies against, there is no adapter.

## Links

`partners.pegasuslogistics.com/Tracking/ShipmentTrackingWithoutLogin?ID=<number>` opens one shipment.
