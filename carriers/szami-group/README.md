# SZAMI Group

SZAMI Group parcels use enabled universal providers. There is no dedicated adapter.

SZAMI Group Logisztikai Szolgáltató Kft. delivers and installs large household appliances in
Hungary for retailers. Its site is szamigroup.hu.

## Numbers

Its tracker takes the reference number the retailer gives the customer. No public page shows
one, so there is no rule.

## Why there is no adapter

The tracking page posts that reference (`hivszam`) with a form token and shows the delivery's
details without personal data. With no public number to check its replies against, there is no
adapter.

## Links

The form posts the reference with a token, so no address opens one item.
