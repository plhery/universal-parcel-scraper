# Interlogistica

Interlogistica parcels use enabled universal providers. There is no dedicated adapter.

Interlogistica is a Bulgarian courier and freight forwarder, GLS's network partner in Bulgaria.
GLS parcels from abroad keep their GLS number, and Interlogistica's tracker carries on their
history once they reach Bulgaria. Its site is interlogistica.bg.

## Numbers

No public page shows an Interlogistica shipment number, so no rule names it.

## Why there is no adapter

The tracker answers a form post without a session or CAPTCHA, but no public number has been
found to check its answer with. It shows an unknown number as an empty table.

## Links

The tracker takes numbers only by form post, so no link opens a number.
