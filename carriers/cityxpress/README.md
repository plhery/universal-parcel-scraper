# CityXpress

CityXpress parcels use enabled universal providers. There is no dedicated adapter.

CityXpress (City Express Courier) is a courier in Thessaloniki, Greece. Its site is cityxpress.gr.

## Numbers

No public page shows a CityXpress number or its layout, so there is no rule.

## Why there is no adapter

Its tracking page runs on Pegasus Hermes, the courier software behind
[Pack-Man](../pack-man/README.md)'s former voucher search, and shows a voucher's status, order
number and the partner's voucher when another courier delivers. With no public number to check its
replies against, there is no adapter.

## Links

The voucher search opens numbers from its `r18p01` parameter.
