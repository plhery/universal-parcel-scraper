# Plus Cargo

Plus Cargo shipments use enabled universal providers. There is no dedicated adapter.

Plus Cargo ships balikbayan boxes from Sydney to the Philippines.

## Numbers

No public page shows one of its box numbers, so there is no rule.

## Why there is no adapter

The tracking page asks `GET /trackCargo/<box>/<0 or 1>` on the same site. With no public number to check its
replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
