# Asigna

Asigna parcels use enabled universal providers. There is no dedicated adapter.

Asigna (Comunicación y Logística Canaria) carries parcels, groupage and customs between
mainland Spain and the Canary Islands. Its site is asigna.es.

## Numbers

An expedition number is seven digits, a length many carriers share, so no rule names it.

## Why there is no adapter

The tracker asks for the recipient's postcode with the number, and no public number has been
found to check its answer with.

## Links

The tracker takes the number and postcode from a form, so no link opens a number.
