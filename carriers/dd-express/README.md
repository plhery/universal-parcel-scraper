# DD Express

DD Express parcels use enabled universal providers. There is no dedicated adapter.

DD Express Sdn Bhd, also called DD Cold Chain, delivers chilled and frozen e-commerce parcels
door to door in Peninsular Malaysia and Singapore. Its site is dd.express.

## Numbers

No public page shows a DD Express tracking number, so its layout is unknown and no rule names it.

## Why there is no adapter

The tracker's lookup answers without a key or CAPTCHA, but no public number has been found to
check it with.

## Links

The tracker opens one or more numbers from its `tracking_ids` parameter.
