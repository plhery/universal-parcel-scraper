# VTL

VTL shipments use enabled universal providers. There is no dedicated adapter.

VTL Vernetzte-Transport-Logistik, from Fulda, is a cooperation of more than 120 general-cargo hauliers in Germany and
Europe. A partner haulier's consignment travels under the network's numbers and is tracked on this page, so members are not
separate carriers.

## Numbers

The tracker takes VTL's consignment number or the colli's SSCC. Neither has a public sample, so there is no rule.

## Why there is no adapter

Each lookup posts the number and the recipient's postcode back to the page. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
