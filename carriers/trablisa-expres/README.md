# Trablisa Exprés

Trablisa Exprés parcels use enabled universal providers. There is no dedicated adapter.

Trablisa Exprés is the courier unit of the Trablisa group in Palma, Mallorca, with offices in Ibiza
and Menorca. It carries business document pouches and parcels across the Balearic Islands, and
on to mainland Spain and abroad.

## Numbers

No public page shows a Trablisa Exprés number, so there is no rule.

## Why there is no adapter

The tracker is the company's tenant of the IRIS courier software on `trablisa.factapp.es`. No public
number is known to check its replies against.

## Links

`/IRIS/Seguimiento?s=<number>` opens one shipment, so the catalog links each number there. Each IRIS
tenant keeps its own shipments, so links are read only on the company's tenant.
