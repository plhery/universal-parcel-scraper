# Crossflight

Crossflight parcels use enabled universal providers. There is no dedicated adapter.

Crossflight is a privately owned international express courier in Colnbrook, near Heathrow. It
carries express parcels, freight and mail worldwide and runs fulfilment. Its site is
crossflight.com.

## Numbers

No public page shows a Crossflight number, so there is no rule.

## Why there is no adapter

Its tracking page at `my.crossflight.com` takes one or more numbers through a GET form and shows
each one's status summary. Full details need a myCrossflight login. No public number is known to
see a found reply.

## Links

`my.crossflight.com/shipping/tracking/tracking.jsp?shipmentNumbers=<number>` opens one shipment,
and so does the header box's `my.crossflight.com/tracking/tracking.action` with the same
parameter.
