# GIO Express

GIO Express parcels use enabled universal providers. There is no dedicated adapter yet.

GIO Express is a courier and logistics company in New York, mostly for business customers.

## Numbers

No public page shows a GIO Express order number, so no rule names it.

## Tracker

The tracking page relays a dispatch portal that asks for the order's key beside its number.

## Links

The tracking page reads the number from its `tracking` parameter.
