# Big Post

Big Post parcels use enabled universal providers. There is no dedicated adapter.

Big Post is an Australian freight booking service for bulky goods. It books cartons, pallets and
oversized items with partner carriers for delivery to homes, businesses or its depots. Its site
is bigpost.com.au.

## Numbers

Its tracking numbers are seven digits. That fits many other carriers' numbers, and no public page
shows one, so there is no rule.

## Why there is no adapter

Its tracking page posts the number with the delivery postcode through a stateful form, and the
links it sends customers carry a token for one booking instead of the number.

## Links

The tracking page takes the number and postcode in its form, so no address opens one parcel.
