# Fixtures

- `signed.html`: the tracking page's reply for the public sample in `numbers.json`, with the courier's name, the
  courier's and the stations' phone numbers replaced by synthetic ones of the same shape. The rest, the firm's
  own hotline among it, is as received.
- `not-found.html`: the reply for an invented number, as received: the result table with its header and no row.
