# Alaska Air Cargo

Alaska Air Cargo shipments use enabled universal providers. There is no dedicated adapter.

Alaska Air Cargo carries freight, mail and parcels on Alaska Airlines' flights, Alaska and Hawaii included; Hawaiian
Air Cargo's site now leads to it.

## Numbers

Its air waybills are the airline's three-digit prefix and eight digits, a shape every airline shares, so there is no rule.

## Why there is no adapter

The cargo portal's Tracking tab works without an account. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
