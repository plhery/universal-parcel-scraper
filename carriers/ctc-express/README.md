# CTC Express

CTC Express parcels use enabled universal providers. There is no dedicated adapter.

CTC Express (全統物流, Chyuan-Toong Logistics) is a Taipei express carrier delivering parcels across Taiwan from
its own stations. Its site is ctc-express.com.tw.

## Numbers

Its tracker takes a consignment note, query or hand-written note number (托運單號, 查件單號, 手開單號). No public
page shows one, so there is no rule.

## Why there is no adapter

Its tracker posts the number to its own JSON API with an image CAPTCHA, which the server checks.

## Links

Its tracker has no address for a single number, so no link names it.
