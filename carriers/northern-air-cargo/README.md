# Northern Air Cargo

Northern Air Cargo shipments use enabled universal providers. There is no dedicated adapter.

Northern Air Cargo, from Anchorage, flies freight across Alaska and to the lower 48 states.

## Numbers

Its air waybills are the prefix 345 and eight digits. No public page shows one, so there is no rule.

## Why there is no adapter

The tracking page posts the air waybill. With no public number to check the tracker's replies against, there is no adapter.

## Links

The tracker takes the number only from its form, so no address opens one shipment.
