# Savino Del Bene

Savino Del Bene shipments use enabled universal providers. There is no dedicated adapter.

Savino Del Bene, from Scandicci near Florence, forwards road, sea and air freight worldwide and delivers furniture and
bulky goods.

## Numbers

The tracker takes an air waybill, a house waybill, a bill of lading, a container number or a customer reference. No
public page shows one, so there is no rule.

## Why there is no adapter

The site's quick search sends the number and its document type to the tracker. With no public number to check the tracker's replies against, there is no adapter.

## Links

The quick search opens `fastTrackingView.xhtml?holding=SAVINO_DEL_BENE&field=<type>&value=<number>`; the link rule
reads the number. The catalog's link template cannot name the document type, so there is none.
