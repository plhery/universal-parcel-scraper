# Security

Report vulnerabilities privately through [GitHub security advisories](https://github.com/plhery/universal-parcel-scraper/security/advisories/new).
Include a synthetic reproduction and the affected version. Do not put parcel credentials,
tracking links, recipient details or secrets in a public issue.

The HTTP API binds to localhost by default. Configure a bearer token and your proxy's own
request limits before sharing it. Treat capability links and destination postcodes as parcel
credentials. TRAWL belongs on a private network. Keep dependencies and browser images current.
