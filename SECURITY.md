# Security

## Reporting

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/plhery/universal-parcel-scraper/security/advisories/new).
Include a synthetic reproduction and the affected version. Do not put parcel credentials,
tracking links, recipient details or secrets in a public issue.

## Running it

The HTTP API binds to localhost by default. Before sharing it, configure a bearer token and
your proxy's own request limits. Treat capability links and destination postcodes as parcel
credentials. Keep TRAWL on a private network, and keep dependencies and browser images
current.
