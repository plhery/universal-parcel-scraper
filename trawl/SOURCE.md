# TRAWL source

The Dockerfile extends germondai/trawl at tag `v1.5.0`, commit
`c81d628b4d509ceb6e4ae4567f0ffb62d4eeb051`, with the image digest pinned in [Dockerfile](Dockerfile).
[Upstream source](https://github.com/germondai/trawl/tree/c81d628b4d509ceb6e4ae4567f0ffb62d4eeb051)
and [source archive](https://github.com/germondai/trawl/archive/c81d628b4d509ceb6e4ae4567f0ffb62d4eeb051.tar.gz).

The patches, installation script and build instructions live in this folder and are distributed
under [AGPL-3.0](LICENSE). Release builds attach the matching upstream and patch source archives.
Keep that source available with any redistributed image.
